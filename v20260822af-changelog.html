🗺️ 地图方案 · 待您选择

现在地图用的是 assets/_pv_ref.png（一张水墨山水参考图）+ 13 个 SVG 透明命中区 + 拖拽/缩放交互。 您这次给的截图（手机山河志面板）正好展示了另一种思路 — 完全不同的"地图"概念。请挑一个：

A. 列表式地图

取消 PC 拖拽画布，改为您截图里那种「山河志」风格——按州分组的卡片列表，每州内是该州的全部地区（dot + 名字标签），点击地区直接跳转。
 优点：手机体验极佳，信息密度高，符合率土之滨/三国志战略版/江南百景图等主流三国策略手游惯例；零缩放歧义。
 代价：失去地理空间感（但本来 CSS 缩放就已经糟）。
 工作量：~半天，改动集中在 buildShanhzhiHTML 和 renderMap，CSS 改动少。

B. 缩略图 + 列表混合

顶部留一小块可缩放的缩略图（13 州彩色色块按真实位置排布，3 档缩放），下方是当前选中州的地区列表。两部分联动。
 优点：同时有全局感和详情，移动/PC 通吃。
 代价：信息架构略复杂，需要为缩略图做选州交互。
 工作量：~1 天。

C. SVG 矢量风格地图

保留拖拽画布但底图换成纯 SVG 矢量绘制——州轮廓用 path 路径 + 渐变填色 + 高光描边，州内地区用 SVG dot + label；字体隶书矢量抗锯齿，缩放永远清晰。
 优点：视觉最专业、最像 3A 手游；缩放无失真；可动态改色（玩家领地/中立/已探索不同色）。
 代价：需要把 13 州的轮廓点阵重新画成 SVG path（可用您给的那张图作参考）。
 工作量：~2 天（州轮廓绘制是最费时的一步）。

D. 换更精致的图源

保留当前 PNG + SVG 透明命中区架构，但换一张更精致/更"三国水墨"的底图（比如您 8/21 给的那张更经典的古卷手绘），并加上 SVG 风格的州名落印（朱红 + 隶书）。
 优点：改动最小，立竿见影；维持现有可缩放交互。
 代价：仍然受限于底图分辨率；只换皮不换骨。
 工作量：~2 小时（换图 + 微调 CSS）。
