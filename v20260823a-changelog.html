🏙 城市系统（第一版）

每个城市新增三项基础参数（0–100 相对值），数据驱动、按参数实时生成内容，而非为每城手写房间：
参数作用
人口 pop决定城市规模等级（巨邑 / 大城 / 州城 / 县城 / 边邑）与城中百姓 NPC 数量
治安 order低治安城市出现「落单溃兵」敌人（可挑战）；并出现「维持治安」行动
商业 commerce高商业城市出现「行脚商贩」（可交易）与「逛市集」行动
  • 进入城市先报城郭概况：如「〔城郭·邺城·冀州〕大城｜户口数十万｜夜不闭户｜市井兴旺」
  • 城中人物随参数变化：人口越多百姓 NPC 越多；治安低则有溃兵出没；商业高则有行商可买卖
  • 全套参数覆盖司隶（洛阳）、幽州（蓟城 / 渔阳）、豫州（颍川）及十三州全部州治所（邺、昌邑、下邳、临淄、襄阳、寿春、成都、武威、晋阳、番禺）
  • 「维持治安」「逛市集」复用已有事件（溃兵劫掠 / 西域行商），行动随参数增减

🧩 设计取舍

  • 采用「单房间 + 参数派生」而非「每城手写 N 个房间」：城市仍是地图上的一个节点，进入后内容由参数动态生成——扩展新城市只需在 cities.js 加一行数据
  • 参数为静态基准值，后续可接玩家行为（如剿匪提升治安、行商提升商业）形成轻度成长闭环
