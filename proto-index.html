战斗画面重构 · 原型对比

三个方案均为零美术素材、纯代码实现。点开各自演示，凭观感决定方向。 目标：在「骑砍式千军万马」+「无双式割草演出」之间，找到不依赖美术资源也能出效果的做法。
原型 A · Canvas 兵海 + 文字演出推荐

两军数百单位在 Canvas 上对冲、混战、溃散；斩将时全屏「斬」字印章砸下 + 白光 + 慢动作。最贴近骑砍战场 + 无双割草，且性能可上万单位。

 原型 B · 纯文字电影战报

完全放弃图形，用流式巨字战报 + 关键词高亮 + 拟声词（破！斬！）+ 数字滚动推进，信长/太阁风。成本最低，但缺大场面画面感。

 原型 C · 极简几何 + 速度线

三角=兵、圆=将、线=冲锋轨迹，靠镜头震动、速度线、墨溅营造无双爽感。比写实 SVG 干净，但千军万马表现力有限。

 原型 A+B · 兵海战场 + 文字战报（组合）

底层 Canvas 兵海打千军万马（A），上层电影式文字战报推进（B），斩将触发全屏「斬」印章。兼顾大场面与叙事节奏。

 原型 · 纯文字武侠（落魄剑客 · 江湖遭遇）已定方向

武侠风：你饰落魄剑客，夜走荒山撞上三名江湖败类。全程纯文字演出——个人战文字交互（风扫落叶/铁壁/踏雪无痕/绝学·惊鸿照影/遁走），门派视角是纯文字战报（弟子数字滚动、斩将「斬」印章）。 内核同一套 resolveAttack，区别只在"描写尺度"，从一人到千军都能写。角色全凭文字塑形，弃用旧版卡片/头像。
方向已定：以 统一内核（分形战斗模型） 为地基，开局身份 = 落魄剑客 / 江湖浪人（武侠个人向、遭遇战为主、弱门派）。 表现层采用 纯文字（文字交互 + 文字战报 + 印章特效），零素材、最能灵活覆盖从个体侠客到门派千军的各类效果与野心。角色不再用卡片/头像，全凭文字描写。同一套 resolveAttack 驱动所有尺度，后续平滑升级为门派、武林大会、侠义抉择、书信门规。
