🏯 城市网格系统（程序生成房间）

每个启用 grid 字段的城市，进入后展示一张 N×N 的城内房间网格，点击相邻格移动，而非单一房间。房间内容由格子类型实时派生：
格子类型城内表现可交互
🏛 城中广场州衙旌旗、商旅如织就地休整 / 维持治安
🚪 城门出城门户返回山河志（出城）
🛒 市集摊贩鳞次逛市集（交易）
🏠 民宅寻常百姓家交谈百姓 / 休整
⚔ 军营旌甲林立募兵操练（入队）
🌾 农庄田垄新绿与农夫交谈
🟫 空地 / 🔥 焦土未营建 / 劫后（预留扩建 / 战火降级）
  • 规模分级：都城洛阳 9×9、州城 7×7（邺 / 昌邑 / 下邳 / 临淄 / 襄阳 / 寿春 / 成都 / 武威 / 晋阳 / 番禺）、县城颍川 5×5
  • 布局稳定：用基于城市 id 的种子伪随机生成，同一城每次进入布局一致；布局存入 state.flags.cityGrid 持久化（旧档兼容）
  • 移动：仅可点击与当前格上/下/左/右相邻的格子；当前格高亮，远处格子置灰不可瞬移
  • 内容随参数：商业越高市集越多、城防越高军营越多；治安低则城中广场 / 街巷刷出「落单溃兵」（可挑战）
  • 蓟城、渔阳保留原有手写多房间街区（不启用网格，避免覆盖既有内容）

🧩 设计取舍

  • 采用「类型矩阵 + 派生」而非手写 81 个房间：只存一张字符矩阵（每城约 N×N 个类型），房间内容全靠 cityCell* 派生——加城市只需在 cities.js 加一行并标 grid
  • 网格是扩建 / 降级的载体：后续 grid 边长随 pop/wall 增长解锁外圈空地，战火使 wall 跌破则标记 ruin 焦土（已预留类型）
  • 复用既有 renderRoom / move / state.flags 体系，对原架构几乎零侵入
