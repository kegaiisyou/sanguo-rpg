## 30 秒技术速览

- **纯静态**：无后端、无构建流水线，打开 `index.html` 就能玩
- **源码 / 产物分离**：源码在 `shared/`，浏览器实际加载 `shared/bundle.js`
- **改了 `shared/*.js` 必须重建**：`python tools/bundle.py`（**跑两次**）—— 否则线上完全不变
- **发布**：推 `main` 分支 → GitHub Pages 自动更新

最小改动流程：

```
改 shared/*.js
  → python tools/bundle.py（跑两次）
  → 版本号三处对齐
  → node --check shared/bundle.js + 两道 test/ 门禁
  → 浏览器实测
  → git commit + push
```

详见 [02-开发流程与版本迭代](docs/01-工作说明/02-开发流程与版本迭代.md)。
