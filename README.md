# 乱世烽火 - 开发文档

## 项目概述
东汉末年 · 文字武侠 · 开放世界 RPG 游戏（三国背景作外包装），纯 HTML/CSS/JS 实现

---

## 当前阶段
**核心框架 v0.2.0（已落地可玩闭环）**

- 水墨标题屏：四入口（仗剑入世 / 拾卷续缘 / 览物志 / 整肃），三档存档，死亡回标题
- 战斗系统：12 招式数据（9 招式 + 3 发力技巧，含绝技回马枪）+ 10 敌模板 + 4 AI + 华雄 Boss，半手动 / 自动战斗，伤害公式与 Buff/Debuff
- 武学系统：13 艺线 + 12 招式数据 + 门槛锁 + 发力技巧 + 境界突破 + 命中判定
- 装备系统：四槽 + 5 档品质 + 耐久，战斗掉落接入属性
- 善恶双轨：侠义 / 凶名独立双轴 + 阈值解锁 + NPC 态度
- 资源硬性限制：食 / 水 / 精力，力竭封锁、休整恢复
- 历法 + 天候 + 山河志空间地图 + NPC 浮层菜单
- 设置面板：标签页（画面 / 声音 / 游戏），标题页同款但无调试台
- 世界规模：**61 场景房间 / 43 对话对象 / 8 事件**

## 🎮 操作说明
- 移动：通过场景出口卡片在房间间前往（部分房间支持方向键 / WASD）
- 交互：点击场景对象（人物 / 建筑 / 物件 / 出口）展开卡片或浮层菜单（交谈 / 观察 / 攻击 / 移动）
- 战斗：手动选招或开启自动战斗；战意满槽放绝技
- 设置：底部 dock「设置」或标题页「整肃」打开标签页设置
- 调试台：URL 加 `?dev=1` 显示
