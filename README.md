### 山河志空间地图（本次大迭代 v20260820av→be）
- **字体模糊根因修复**：HTML 标签从 `.map-grid` 抽出到兄弟层 `.map-overlay`，杜绝双层 transform 破坏文字抗锯齿
- **放大看不到房间修复**：缩放只作用于 `.map-grid`（`.map-viewport` 仅平移），overlay 不再被二次缩放
- **地图旅行**：点击房间节点可直接前往（消耗同步行）；点击州/城精确居中（仿射坐标对齐）
- **北上路线打通**：白檀军屯整体北移（渔阳北门 → 白檀营门 → 白檀屯寨 → 燕山山口），解决"渔阳北门无路"
- **范围修复**：仿射范围扩展至 `COL -13..19 / ROW -15..21`，燕山等北方区域完整纳入地图
- **表现力优化**：宣纸质感底纹（纯 CSS）、去除十三州色块与州界线、州名防遮挡错位 + 印章红区域题字、古朴北针、图例移入地图内不挡标题、初始缩放以当前房间为中心落在区域档

## 🎮 操作说明
- 移动：通过场景出口卡片在房间间前往（部分房间支持方向键 / WASD）
- 交互：点击场景对象（人物 / 建筑 / 物件 / 出口）展开卡片或浮层菜单（交谈 / 观察 / 攻击 / 移动）
- 战斗：手动选招（攻击 / 防御 / 道具 / 撤退）；战意满槽放绝技
- 设置：底部 dock「设置」或标题页「整肃」打开标签页设置
- 调试台：URL 加 `?dev=1` 显示
