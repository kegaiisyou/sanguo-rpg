② 地图直接用用户简化版参考图

问题根因：之前 .map-grid 的 background 引用了 background:url('ScreenShot_20260821_230620_978.png') ...， 这是用户截图的本地文件路径，项目根目录根本不存在该 PNG， 因此浏览器静默回退为空白背景，屏上看不到任何州界/州名——之前会议上又叠加了羊皮纸、水洗、米黄 multiply 等多层污染，最终效果非常糟。

改动前（用户反馈："丑爆了"）

.map-grid{
  background:url('ScreenShot_20260821_230620_978.png')
    center/100% 100% no-repeat;
}
/* 此文件不存在 → 空背景 */
/* + .map-bg 羊皮纸 inset shadow */
/* + .map-fade multiply 水洗层 */
/* + .map-region 彩色区域圈 */
/* + .map-state-sh 描边+隶书州名 */
/* = 视觉污染、州界错位、双字 */

改动后（用户极简参考图）

.map-grid{
  background:url('assets/_pv_ref.png?v=20260822ae')
    center/100% 100% no-repeat;
}
.map-bg,.map-fade{display:none}
.map-canvas .map-region,
.map-canvas .map-region-t,
.map-canvas .map-terrain,
.map-canvas .map-svg{display:none}
.map-state-sh{   /* 仅作不可见命中区 */
  fill:transparent;stroke:transparent;stroke-width:0}
.map-state-name{display:none}
/* = PNG 直接呈现 + poly 命中区保持 */
  • 新底图采用 assets/_pv_ref.png（1000×960，与用户截图等比），含完整彩色州块（白、紫、青、橙、黄、桃红、红、绿、棕）+ 蓝色水系（黄河、长江）+ 隶书州名（胖隶书大气）+ 外族注记（匈奴、鲜卑、西域长史府、夷洲）
  • SVG 的 13 州 polygon 改为完全透明，只作不可见点击命中区；hover 时浮出淡黄色高亮，让用户知道命中了哪州
  • SVG <text class="map-state-name"> 直接 display:none，隶书州名由 PNG 承担
  • SVG 海/草原/沙漠的渐变 radial、彩色区域圈、印章题字、房间连线 SVG 全部 display:none——它们过去与 PNG 错位重影，是麻烦的根源
  • .map-canvas 内阴影从 rgba(40,30,15,.35)/70px 减弱到 rgba(40,30,15,.18)/50px，避免压暗这张彩色 PNG

JS 同步清理（不破坏语法）：

  1. apply() 中删除 canvas.querySelectorAll('.map-state-name').forEach(...) 反字号补偿循环（display:none 后无意义）
  2. buildMapHTML() 中 polygon 的 inline fill/stroke 改为 transparent，并删除 <text> 节点生成（PNG 已含隶书，且 CSS 已 display:none）

版本号与缓存号同步

  • shared/index.js 的 defaultSave.version='0.2.0' 是【存档 schema 版本号】，与显示版本无关，按 memory 规则保持不动
