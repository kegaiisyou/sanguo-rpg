🗺 城内网格接入山河图（交互重构）

上一版城内网格以独立区块占用文字输出框，本版将其移入「山河图（山河志）」，并改为与野外地形一致的底部方向键移动：
  • 不再占用文字框：主视图只保留叙述 + 底部方向键 + 当前格动作，网格视觉交给山河图
  • 山河图内展示城内布防图：进入有 grid 的城市后，点开山河图即为该城 N×N 网格，当前格高亮、相邻格可点
  • 方向键移动：底部「北 / 南 / 东 / 西」即城内相邻格（currentRoomExits 由格子坐标派生），与野外移地形完全同款手感
  • 两种方式皆可：在山河图内点相邻格、或用底部方向键，效果一致；村内地图开启时移动会同步刷新网格
  • 出城：动作区「返回山河志（出城）」或城内地图右下「返回山河志（出城）」按钮，强制打开世界山河图离开城市（forceWorld）

🔧 关键改动

  • 移除主视图 #city-grid 区块与 renderCityGridActions（改为城内地图视图）
  • 新增 buildMapCityHTML / initMapCity：在 openModal('map') 时若位于城内且非 forceWorld，渲染并绑定城内网格
  • currentRoomExits：城内房间按当前格上下左右相邻派生方向出口（焦土 ruin 不可通行）
  • move：新增城内分支，按方向在格子间移动；goCell 计入精力/粮水消耗与时间推进，并在山河图开启时刷新
  • buildActions：城内当前格动作（市集/军营/休整/治安/出城）走常规动作区，移动交由方向键
  • 城规模分级（洛阳9×9、州城7×7、颍川5×5）与类型派生逻辑沿用 v20260824a，网格数据仍存 state.flags.cityGrid
