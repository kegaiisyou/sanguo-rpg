四、AI 全程制作 · 工作流建议

本作已形成一套适合「人定方向 + AI 执行」的稳定制作方法，建议固化：

  1. 数据驱动优先：支线/事件/对话/敌人全部落成纯数据（TRIGGERS/EVENTS/DIALOGUES/ENEMIES），新内容只加数据、不动引擎——本批 3 条支线即零引擎改动。
  2. 脚本生成文档：用生成脚本（如 scripts/gen_skill_tree.js）把数据自动导出成可维护文档（武学树/物品表/支线索引），改数据重跑脚本即同步，避免手写文档失配。
  3. 改完即测：每批改动先跑 node 三件套（战斗 45 项 / 交叉引用 15 规则 / HTML 语法），再浏览器实测关键链路，0 报错才提交。
  4. 小步提交 + 可回滚：一个主题一个版本（v20260831r/s/t…），每次都 push GitHub，可随时回退到稳定版。
  5. 批次节奏：单批聚焦 1 个主题（支线/战斗/教程/经济…），做完交付让用户测试反馈，再进下一批——迭代比一次性大改稳定。
  6. 预留钩子：写内容时为未来留伏笔（如「苏娘攀绳、福生传信——留待他日」），后续扩展有现成接口。

下一步建议：先做 P0 三项（任务追踪 + 批量化支线 + 音频基础包），单个版本内可完成并实测，收益立竿见影。
