## 一、制作要求（与 13 兵科完全一致，必读）

### 1. 风格
- 中国**水墨手绘**，宣纸米白底（不透明），墨线为主。
- **统一浓墨**（非淡墨线描），墨色约 `#2b2620`。
- 默认纯墨最稳；本批允许下列**克制微彩**（小面积、不填大片，仅用于辨识材质/符号），其余纯墨：
  - 藤甲兵：藤甲/藤牌可藤褐 `#6b5836`
  - 象兵：象身可灰褐 `#5b534a`
  - 黄巾两系：黄巾（头巾）可克制黄 `#d9b44a`

### 2. 尺寸 / 构图 / 命名
- **正方形**，≥ 1536×1536（推荐 2048×2048）；后台裁切缩放，不用你管最终尺寸。
- **一律半身胸像 / 腰以上特写**：头肩占画幅 60% 以上，**不要全身像**（之前全身像缩到 30px 会糊成条纹）。
- 单人单图，主体居中偏上；主体完整，**道具不切边**（藤牌、象牙、巨械、农具都要完整入画）。
- 无复杂背景、无边框、无文字、无现代/卡通元素。
- **命名**：一张一人，文件名用 `中文名.png`，即 `藤甲兵.png` / `象兵.png` / `黄巾力士.png` / `黄巾军.png`。
- 放目录 `shared/img/art/units/`（与 13 兵科同目录，覆盖/新增均可）。
- 右下角「豆包AI生成」水印可留着，我会自动抹掉。

### 3. 画风统一细则（最关键，请逐条遵守）
- 纸色统一 RGB≈`(250,246,242)` 米白宣纸，不透明。
- 墨线粗细、浓度全组一致；统一光源方向（建议左上）。
- 不要渐变背景、不要装饰花纹边框、不要留白处加印章以外的元素。
- 4 张的「人物在画幅中的占比、留白量」必须接近（参考 13 兵科第 4 张骑兵的半身尺度）。

### 4. 不要做什么
- ❌ 全身像（缩了糊）
- ❌ 复杂场景 / 多人物群像
- ❌ 大面积彩色（仅上列克制微彩可小面积点缀）
- ❌ Q版 / 卡通 / 厚涂 / 3D 渲染
- ❌ 边框文字、标题、水印以外的字样（我会抹水印，但请别在手绘画面上写字）

## 二、4 种兵种的识别要点（逐张说明）

### 1. 藤甲兵（步 · 高防惧火）
- 全身藤甲：藤条 + 生牛皮编织，**土黄/藤褐色，无金属反光**，与铁甲步卒（刀盾、长枪）一眼可分。
- 配 **藤牌/藤盾**（圆盾，藤编纹理）。
- 半身胸像：藤甲 + 藤牌特写，藤牌占画面约 1/3，盾面朝前。
- 可微彩：仅藤甲/藤牌的藤褐 `#6b5836`，墨线为主。

### 2. 象兵（骑 · 巨兽踩踏）⚠️ 本轮最关键差异点
- **必须画大象 + 象奴（驭手）**，体积巨大，**明显区别于 13 兵科里「骑兵」的马首+骑手半身**。
- 巨象可披甲或裸象；**象鼻、象牙必须入画**；象奴半身踞于象背/象颈。
- 半身构图画 **象头 + 象奴上身**（象头占画幅主体，体现巨兽压迫感）。
- 可微彩：仅象身的灰褐 `#5b534a`，墨线为主。
- **不要画成普通骑兵披甲**——这是与现有「骑兵」立绘必须拉开的距离。

### 3. 黄巾力士（步 · 蛮力）
- 巨汉，肌肉裸露/束身，持 **巨械**（大刀 / 石锤 / 狼牙棒），**黄巾（黄头巾）包头**。
- 区别于制式军（甲胄齐整）：力士是裸袒蛮勇、黄巾束发、武器粗放。
- 半身胸像：巨汉上身 + 巨械（巨械不切边）。
- 可微彩：仅黄巾之黄 `#d9b44a`，墨线为主。

### 4. 黄巾军 / 黄巾贼（步 · 廉价量大）
- 农民义军，装备混杂（耙 / 锄 / 竹枪 / 棍棒），**黄巾包头**，衣衫褴褛、带补丁。
- 区别于黄巾力士：力士精壮持巨械；黄巾军瘦削杂兵持农具，更「乌合」感。
- 半身胸像：瘦削义军 + 农具/竹枪 + 黄巾。
- 可微彩：仅黄巾之黄 `#d9b44a`，墨线为主。
