## 一、一句话定位

玩家不是「被 Tutorial 教会的玩家」，而是**一个刚被抓进苦役营的囚徒**：先学会在这座营里活过一天，再在第四日太平道夺营的乱局里，凭自己这几天攒下的**人情**走出营门。

主题句：**「法子不救你，人救你。」** —— 旧版列了九条越狱路线（攀墙/迷药/暴动/木牍/收买/硬闯…），本次全部废弃；如今能走出营门的只剩三条半，每一条都挂在「你跟谁有过交情」上。

## 二、三幕结构

### 幕一 · 入营（序章，一次性）
被掳 → 入狱 → 牢房醒来。主角身上只剩囚服与镣铐（行囊教学从「看清自己还剩什么」起步）。

### 幕二 · 熬（教程期，可反复）
在苦役营里按规矩活下去。核心不是「做任务」，而是**把一天过完**：

| 规矩 | 内容 | 误了的代价 |
|---|---|---|
| 头一条 | 卯时到午时，到中军场院**应名点卯**（验名） | 扣口粮、记旷役，名籍落一笔「失期」 |
| 第二条 | 戌时前回牢过夜，**销名** | 同上；晚归要挨三鞭 |

- **点卯首次手动、其后自动**（`rollTaught` 标一次即转自动），避免教程期天天点同一个按钮。
- 教程期**时辰冻结**在戌——所以首次点卯的教学分支绕过了 `isRollHour`/`curfewSet` 门槛，否则玩家点不动卯。

### 幕三 · 夺营（毕业，第 4 日裁决）
第 4 日（`day>=3`）踏入中军场院 (1,1)、且已出牢（`cellOpen`）时裁决一次，此后 `flags.coup.done` 关闸。
开场白：

> 〔夺营·起爆〕第4日，营中骤变——太平道的旗号已暗里插遍岗哨。你此前的经营，决定这一夜通向何处。

## 三、场景：苦役营九格

```
 (0,0) 农田      (1,0) 牢房      (2,0) 矿坑
 (0,1) 伙房      (1,1) 场院      (2,1) 仓库
 (0,2) 军营      (1,2) 岗哨      (2,2) 演武场
```

| 格 | 主要交互 | 说明 |
|---|---|---|
| 农田 (0,0) | 开垦薄田、伐木场入口 | 接「开垦薄田」才见荒地，一畦一畦开 |
| 牢房 (1,0) | 六间子牢房（面板 doors） | 囚室格本身不放按钮，回牢踏进即自动销名 |

| 场院 (1,1) | **验名点卯**、乱石堆装担、卸料台卸料 | 教程主舞台；夺营裁决点 |
| 仓库 (2,1) | 卸料台、麻袋堆/木箱/货架、仓吏 | 容器式取物 + 存取权限 |

| 演武场 (2,2) | 戳木人桩、韩铁 | 战力教学场 |

## 四、教程目标链（`onbGoalStep` 顺序）

行囊 → 任务 → 叩门出牢 → **点卯** → 装担 → 卸料 → 角色 → 周听涛 → 结交 → 岗哨瞭望

两条关键的「真实操作闭环」（教程不靠无脑按钮推进度，靠真做一遍）：

1. **装担 → 卸料**：乱石堆「装担」担起石料 → 场院「卸料台」卸料入仓。教程期**石料只能这样入仓**（仓库面板对苦役不开放）。
2. **打开 → 取物**：仓库麻袋堆/木箱/货架先「打开」看清里头有什么，再「取物」才真拿走；取空即空、隔天刷新。

## 五、人物

### 5.1 主线人物（决定你走出哪道门）

| 人物 | 位置 | 作用 | 状态 |
|---|---|---|---|
| **牢头** | 场院/牢门口 | 立两条规矩、点卯、销名、晚归三鞭 | ✅ |
| **周听涛** | 同囚 | 星象 + 秦汉典故（陈涉失期、秦发闾左之戍、淮阴侯胯下之辱）。**只做氛围，不预言主角、不落机制** | ✅ |
| **仓吏** | 仓库 (2,1) | 采石充仓 / 仓中翻找 / 淘铜铸镐 三个差；点头才能开库门自取自存 | ✅ |
| **韩铁** | 演武场 (2,2) | 教头。好感 ≥2 → 送信线；**过所符信**由他给出 | ✅ |
| **默叔** | 营中 | 好感 ≥1 且阿禾 ≥2 → 墨家支路 | ✅ |
| **阿禾** | 地字号囚 | 好感 ≥2 → 水沟缺口（默叔未认你则走轻版） | ✅ |

> 注：另有一位**郑刚**，是守库房外哨的武夫，与「仓吏」是两个人；旧文档把二者混称为「仓吏郑刚」，此处已按代码实际情况分开（仓库权限挂 `storeman_kuyilao`）。

### 5.2 营中风物人物（不给出路，只给这座营的质感）

孙老（老驿丞，暗流提示）、钱傻、苏娘（搓绳）、鲁大（伙房）、陈简（刀笔小吏，刻木牍）、林娘（蒙汗草）、崔九（原边军什长，不肯杀良冒功）、苟三、石四、吴算、秦九霄（暗探）、郑贵、赵虎（都伯）、冯二、伍长、李旺、席翁、福生。

**本轮已改写**：这些 NPC 原先各自「挂一条出营的路」（攀墙/迷药/暴动/木牍/收买/硬闯），与收敛后的毕业线冲突，会把玩家引向不存在的内容。现已统一为——**保留风物，去掉已废路线的承诺**：

- 孙老：原句枚举七条路线「随你挑」→ 改为「名目多得是，成的一个也没有……靠的不是法子，是时候」。
- 陈简：仍刻木牍，但点明「骗得过岗哨，骗不过验名的册子」，并指向韩铁的**过所符信**（把旧线索接回活线）。
- 鲁大/林娘：蒙汗草留下作风物与警句，「药放得倒人，放不倒这座营」。
- 苏娘/钱傻/郑贵：保留手艺与消息灵通，去掉翻墙、夺腰牌、收买的话术。

## 六、毕业线（四条，按优先级裁决）

| 优先级 | 分支 | 判定条件 | 出路 |
|---|---|---|---|
| 1 | **officer_letter** 送信搬救兵 | `npcFavor.han_tie >= 2` | 韩铁密令你趁乱出营送信，另给一道**过所符信**闯关卡 |
| 2 | **moshu** 默叔线 | `a_he >= 2` 且 `moshu >= 1` | 墨家支路（大段展开） |
| 3 | **minor_ahe** 阿禾轻版 | `a_he >= 2`（默叔未认你） | 阿禾拽你**猫腰钻进水沟缺口**，大段从简 |
| 4 | **minor** 孤身兜底 | 以上都不满足 | 无门道、无牵绊也能走完——**保证不卡死** |

设计要点：**兜底分支留在最末**。谁都没结交的玩家仍有结局，不会卡在营里出不去。

## 七、徭役考据（秦汉口径）

| 考据项 | 落地处 |
|---|---|
| 名籍 / 验名 | 点卯动作即「验名点卯」；立规文案称名籍上落笔 |
| 城旦舂 | 劳作与修营防定性为「**城旦之役**」（修筑营防的日志前缀） |
| 失期当斩 | 立规文案「名籍上更要落一笔『失期』——失期当斩虽是秦时旧法，营里的鞭子却照旧往下落」；晚归受刑称「两桩都失了期」 |
| 刁斗巡夜 | 场院「铜刁斗」可击鼓 🟡（夜巡旁白仍借既有更鼓系统，未另写） |
| 过所符信 | 韩铁送信线给出，作为出营闯关的硬理由 |

**考据边界**：三国=后世不可讲；战国/秦/西汉=前代可讲。
