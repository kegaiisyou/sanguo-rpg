# 设计系统规定（Design System）

> 目的：防止各面板各自写样式、按钮/圆角/配色漂移，以及"改过头"（如把单击选中改成单击即装备）。
> 所有 UI 改动**必须**消费本文件定义的令牌与原语，禁止写死颜色与圆角。
> 令牌与原语的实际定义见 `shared/css/game.css` 的 `:root` 与"设计系统原语"区块。

## 1. 设计令牌（Token，唯一配色/尺度来源）

| 类别 | 令牌 | 用途 |
|------|------|------|
| 主色 | `--seal` | 朱印红（强调/选中/危险主色） |
| | `--jade` | 青碧（成功/可放置/友好） |
| | `--gold` | 金（标题/边线点缀） |
| 墨色 | `--ink` / `--ink-soft` / `--ink-faint` | 正文 / 次级 / 极淡 |
| 表面 | `--panel` / `--panel-line` / `--paper` | 面板底 / 面板描边 / 浮层纸 |
| 主按钮 | `--btn-primary` / `--btn-primary-fg` / `--btn-primary-bd` / `--btn-primary-hover` | **全游戏主按钮**金棕底·米色字（深褐金底渐变） |
| | `--btn-bd` / `--btn-hover` / `--danger` | 次按钮描边 / 悬停底 / 危险红 |
| 圆角 | `--r-btn`(9px) / `--r-card`(12px) / `--r-pill`(999px) | 按钮 / 面板卡片 / 药丸 |
| 间距 | `--gp`(10px) | 标准间距 |
| 其他 | `--shadow` / `--focus` | 阴影 / 聚焦环 |

**规则**：新增任何颜色/圆角，先用上表令牌；上表没有再在 `:root` 增补并登记，禁止在组件里写 `#xxx` / `rgba(...)` / `border-radius:8px` 之类的字面量。

## 2. 组件原语（Primitive）

| 原语 | 语义 | 用法 |
|------|------|------|
| `.btn` / `.ui-btn` | **主按钮**（金棕底·米色字） | 所有"确认/装备/使用/委任/建造"等主操作 |
| `.btn-ghost` | 幽灵按钮（透明·描边） | 次级/取消/菜单项 |
| `.btn-danger` | 危险按钮（红底） | 丢弃/拆除/解雇等破坏操作 |
| `.btn-sm` | 小号按钮 | 紧凑区（页签内/行内） |
| `.tab` / `.tab.active` | 分页标签 | 面板内切换（买卖/属性…） |
| `.surface` | 表面卡片 | 子区块容器（统一底+描边+圆角+阴影） |

**规则**：
- 任何可点击的主操作都应是 `<button class="btn">`（或 `.btn-ghost/.btn-danger/.btn-sm`），**不要**新造 `.xxx-btn` 类再自己写背景/圆角。
- 面板切换用 `.tab`，子区块用 `.surface`，不要各写一套。
- 按压反馈已有通用兜底规则（`button/.btn/.act/... :active{transform:scale(.95)}`），无需每处重写。

## 3. 交互模型（Interaction Model，禁止擅自改）

- **单击** = 选中并弹出详情（含 装备/使用/卸下/修理/丢弃 等按钮）。
- **双击** = 快捷动作（装备 / 卸下 / 使用）。
- **拖拽** = 移动/交换格子（移动端用 pointer 拖拽，桌面用 HTML5 drag）。
- 破坏性行为（丢弃/拆除/解雇）**必须**二次确认或置于详情按钮中，禁止单击直接执行。
- 店铺/建筑：点击即进入，**直接打开对应模态面板**（买卖/存取/制作/委任…），无需先弹菜单（v20260929：用户定调，菜单方案暂缓、先讨论）。交互物（松散物件 / 可交互设施）若需 2–4 个快捷动作，可走既有 `.obj-menu` 浮动菜单；复杂流程（制作/升级）再开**模态面板**。

> ⚠ 历史教训：v20260928d 曾把"单击=装备"改过头，掐掉选中/丢弃入口；v20260929g 已回退到上方标准模型。任何改动交互模型都需**显式**用户确认，不可擅自"优化"。

## 4. 面板布局约定

- 主面板结构：`modal-card` 内含 标题(匾额) + 主体（常见左右分栏：左装备/右物品，或左列表/右详情）。
- 表面用 `.surface` 或既有 `.pack-left/.pack-right` 风格（紫调=装备、金调=物品），保持区分度。
- 移动端（≤560px）网格降列（如 `.pack-grid` 5→3 列），点击热区≥44px。

## 5. 提交前自检清单（Review Checklist）

- [ ] 颜色/圆角全部走令牌，无新增 `#xxx`/`rgba`/`border-radius:Npx` 字面量。
- [ ] 主按钮用 `.btn` 或其变体，未新造按钮类。
- [ ] 交互模型未被静默改变（尤其背包/商店）。
- [ ] 破坏操作有二次确认。
- [ ] 改了 `shared/*.js` → 跑 `python tools/bundle.py`（连跑两次），并手动 bump `index.html` 里 `game.css?v=`；`constants.js` 的 `VERSION` 与所有 `?v=` 对齐。
- [ ] 单一职责提交，描述含版本号，便于审查回溯。

## 6. 物品格子与详情（统一规范，v20260929i 落地）

所有"摆放物品的格子"界面——背包(`pack`)、战利品(`cs`)、仓库(`storage`)、给与(`give`)、工作台材料区（若有）——**必须**统一：

- **网格类**：共用 `.pack-grid` 与 `.cs-grid`（二者现已等价）：桌面 `repeat(5,minmax(0,1fr))`、手机 `≤560px` 降为 `repeat(3,…)`、`gap:6px`。
- **单元格**：统一 `.packcell`（正方形 `aspect-ratio:1/1`，金/深色表面随容器，点击热区≥44px）。**禁止**为某个格子再写独立的 `grid-template-columns` / `min-height` / 图标字号覆盖（v20260929i 已清理 `cs-grid` / `give-grid` / `shop-*` 的散落覆盖）。
- **详情**：统一用 `.loot-info` 浮层 + `.li-*` 内容，布局一致。**`.li-name` 不再显示图标**——格子本身已显示缩略图标，重复图标删除；图标仅保留在"无缩略图"的场景（图鉴/codex）。
- **拖动鬼影**：背包/战利品拖动时显示物品图标（`.pack-ghost` / `.loot-ghost`），**禁止**显示纯文字名（v20260929i 修背包回退成文字的 bug）。

> 新增任何"物品网格"界面，直接套 `<div class="pack-grid">…<div class="packcell">…</div>…</div>`，不要另起一套列数/尺寸。

版本号格式：`YYYYMMDD` + 字母（如 `20260929i`），唯一来源 `shared/config/constants.js` 的 `LF.CONSTANTS.VERSION`。
