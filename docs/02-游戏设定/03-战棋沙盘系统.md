# 战棋沙盘系统（SRPG 会战）

> 版本：`v20261031b`（与 `shared/bundle.js` / `game.css?v` 同步强刷）
> 代码位置：`shared/core/battlefield.js`（逻辑）+ `shared/data/battlefield.js`（数值/配置）+ `shared/css/game.css`（棋盘样式）
> 构建：`tools/bundle.py`（改完源码后连跑两遍，自动写 `index.html` 的 `bundle.js?v` 与 `game.css?v`）

战棋是「剧情/地图遭遇战」落地为格子会战的玩法。本系统把抽象的营级战斗变成可走位、可择令、可看反馈的方格对战。本文档与代码保持一致，便于调参与扩展。

---

## 1. 棋盘与单位

- 逻辑棋盘 `w × h`（默认 `14 × 12`，可被 `cfg.grid` 覆盖）。双方从两端入场，中间留机动纵深；攻城战守方贴右、攻方贴左并加城垣。
- 单位由 `toCell()` 把营级数据扩展为棋盘单位：`atk/def/spd/hp/morale/troopType/rank`，并换算出 `move = BF_MOVE(spd)`、`range = BF_RANGE(slot)`。
- 兵科 → 兵槽（slot）：步 / 骑 / 远 / 械 / 辅。射程：远（弓弩）= 2 格，其余 = 1 格。
- 未带 `troopType` 的守/攻军由 `inferType(name)` 按兵名补类型，保证克制在剧情战也生效。

## 2. 三大策略支柱（一期落地）

### 2.1 兵种克制 `BF_COUNTER`
- 克制环：**长枪 → 骑 → 弓 → 枪**（长枪克骑、骑克弓、弓克枪）。
- 系数：`BF_COUNTER_MUL = { adv: 1.25, dis: 0.8 }`。克制方 ×1.25 伤害，被克方 ×0.8。
- 接入 `dmgRoll` 的 `counterMulOf()`，战报实时标注「（克制）/（被克）」。

### 2.2 地形 `BF_TERRAIN`
| 地形 | moveCost | defMul | atkMul | dodge | 备注 |
|---|---|---|---|---|---|
| 平原 plain | 1 | 1.0 | 1.0 | 0 | 默认 |
| 林 forest | 1 | 1.4 | 1.0 | 0.15 | 守方减伤+闪避 |
| 丘 hill | 1 | 1.3 | 1.2 | 0 | 攻方增攻、守方减伤 |
| 河渡 river | 2 | 1.0 | 1.0 | 0 | 移动消耗加倍（可阻断） |
| 营垒 camp | 1 | 1.5 | 1.0 | 0.10 | 守方减伤+闪避 |
| 城垣 wall | 1 | 1.7 | 1.0 | 0.20 | 攻城战守方 |

- 每局由 `BF_GEN_TERRAIN(w,h,mode)` 在逻辑盘散布（出生列净空；攻城战右侧加城垣）。
- 移动用 **Dijkstra**（`reachable()`），按地形 `moveCost` 累加真实代价；`pathBetween()` 同步。
- 伤害链接入：攻方站格 `atkMul`（丘）、守方站格 `defMul`+`dodge`（林/丘/营垒/城垣）。
- 棋盘渲染地形底色 + 图标。

### 2.3 阵型 `BF_FORMATION`
| 阵型 | defMul | atkMul | move | 定位 |
|---|---|---|---|---|
| 本阵 benzhen | 1.0 | 1.0 | +0 | 默认 |
| 方圆 fangyuan | 1.3 | 0.9 | −1 | 铁桶防守 |
| 锋矢 fengshi | 0.85 | 1.2 | +1 | 尖刀突击 |
| 鹤翼 heyi | 1.1 | 1.05 | 0 | 两翼包抄 |
| 长蛇 changshe | 1.0 | 0.95 | +2 | 拉长行军 |

- `列阵` 面板可点击切换（高亮当前阵），写入 `u.formation` 实时生效于伤害链；单位显示阵型角标，营情面板显示当前阵。

## 3. 军令（攻击指令）

`LF.ARMY_ORDERS` 定义军令：`普攻 / 夹击 / 强袭 / 急袭 / 防御 / 突击` 等。每个军令带 `dmgMul`、`defend` 等标记。
- 玩家点己方营 → 行动菜单 → `攻击` → 选目标 → **军令菜单**（见 §4.2 预览）。
- `pickAiOrder()` 取该单位可用军令中 `dmgMul` 最高者；`pickCounterOrder()` 取反击军令。

完整伤害公式：
```
伤害 ≈ atk × 军令dmgMul × terrainAtkMul × counterMul × moraleAtkMul × formationAtkMul
       × (1 − min(0.8, def×terrainDefMul×formationDefMul / 100))
       再叠加 ±10% 浮动、暴击(×2)、闪避(命中率=max(5%,95%−守方dodge))
```

## 4. 可见性 / 反馈（P1 体验增强）

### 4.1 战报面板
- 战斗内每步既写入 `board.log`（界面可读），也走引擎日志。
- 棋盘底部 **战报面板** 滚动显示最近 7 条（交锋 / 危险 / 提示 分色），解决「打了啥不知道」。

### 4.2 威胁覆盖可视化（点敌方预览）
- 我军阶段**点选敌方营**，高亮其威胁范围：
  - **黄框** = 该敌可移动格（`reachable`）。
  - **红框** = 从所有可达格起、其射程能覆盖到的攻击范围。
- 详情条显示该敌「攻/防/移/射」与说明，点空白关闭。

### 4.3 伤害 / 命中预览
- 选「攻击」并点目标后，军令菜单**每个军令实时显示**：`预计伤 X · 命中 Y%`，并标注 `克制 / 被克 / 将遭反击`。
- 由 `dmgEstimate()` 取期望中心（不含随机暴击/闪避抖动），让玩家在下令前权衡。

### 4.4 节奏控制（1× / 2× / 3× + 跳帧）
- 操作条新增速度分档与 `跳帧` 开关，写入 `board.speed` / `board.skip`。
- 所有动画与 AI 延时经 `D(ms)` 统一缩放；`跳帧` 时动画与延时归零、直接结算，快速跑完大兵团与多回合。
- 适配「长棋盘 + 逐单位慢放」导致的等待痛点。

### 4.5 溃散预警
- 单位满足 `hp/maxHp < BF_ROUT.hpRatio(0.5)` 或 `morale < BF_ROUT.morale(45)` 时，棋盘上显示红色边框 + `危` 角标，详情条提示「溃散风险高」，便于玩家保护或收割。

### 4.6 全舞台模式（不再是窗口小卡）
- 战场渲染会为 `#modal` 加上 `bf-full`（并辅以 `:has(.bf-root)` 自动生效），抹掉弹窗的 24px 内边距与 `max-width:440px` 限制，**整屏平铺**，棋盘可视面积最大化、支持拖动平移。
- 内容被替换（战斗结束）时自动还原常规弹窗样式，不影响其他面板。

### 4.7 详情 / 列阵：内嵌抽屉，不再另开窗口
- 点「详情」「列阵」不再是独立弹窗，改为战场内底部抽屉 `#bf-sheet`（半屏、可滚动、点关闭或遮罩收回）。
- 选阵后仅收起抽屉，**不会再误关整个战场**（旧版 `closeModal()` 会把战场一起关掉）。

### 4.8 统一结束回合 / 连跳下一营
- 操作条 **`结束回合`** 为主操作（金色强调键），一键结束，无需逐个点「待机」。
- 按钮实时显示剩余未行动营数：`结束回合（余 N）`；状态提示为 `我军调度中 · 余 N 营`，全部行动完显示 `全军已待命`。
- **`下一营`** 键：直接跳到下一个未行动的我军营并弹出指令菜单，免去在棋盘上翻找单位。

### 4.9 交互与界面微调（v20261031b）
- **指令面板贴附单位**：「移动/攻击/待机/详情/列阵」浮层与攻击选目标后的军令菜单，不再固定贴在战场底部，而是**浮在所选/目标单位旁边**，缩短与目标的视觉距离、减少横屏扫视。
- **通用弹窗关闭键归位**：关闭按钮从「卡片外贴屏幕边角」移入卡片内右上角（40px 触控友好），不再难点；战棋全屏自带关闭，自动隐藏通用按钮。
- **弹窗限高可滚动**：弹窗最大高度收敛至视口内并支持滚动，外边距由 24px 收到 16px，缓解「窗口太大」的观感。
- **战棋整屏地图 + 浮层 HUD（v20261031b）**：棋盘改为全屏铺底，顶栏 / 详情 / 战报 / 操作条改为半透明浮层；格子尺寸按视口等比缩放铺满（整张战场一次看全），并用安全边距预留顶/底 HUD，避免单位被遮挡。

## 5. 战前部署 / 调试 / 结算（P2）

### 5.1 战前部署（setup）
- 调用 `LF.createBattlefield(ctx).start({ setup:true, ... })` 时，**先弹出「战前部署」全屏面板**（不再直接进入战斗），由玩家自由配置后再开战；普通脚本战不传 `setup` 则照旧直开。
- 面板可配置：
  - **战场大小**：小(8×6) / 中(12×9) / 大(14×12) 预设，或自定义宽高（6–40）。
  - **我方 / 敌军部署**：每方 1–6 营，逐营选「兵种 / 阵位 / 兵力」，可增删。兵力经 `bfAggF`（幂律）换算为 hp/atk/def。
  - **调试功能**（见 §5.2）。
- 点「开始战斗」即按所选配置生成 `cfg` 并 `beginBattle`；点「取消」收起面板。

### 5.2 调试功能（debug flags）
- `invincible`：**我军无敌**，伤害结算 `applyDamage` 对 ally 直接免伤（用于压测/演示）。
- `showAllThreat`：**全体敌军威胁**叠加显示（淡红框覆盖所有敌方可攻击格），一眼看清危险区。
- `enemyIdle`：**敌军不行动**，敌阶段直接跳过 AI 进入下回合（单方演练）。
- `seed`：**固定随机种子**（mulberry32），伤害浮动/暴击/闪避/溃散可复现。
- `speedDefault` / `skipDefault`：开局默认倍速与跳帧。
- `maxRounds`：回合上限，到限按双方总兵力判定胜负（已实现于 `checkOver`）。

### 5.3 战斗结算画面（result）
- 战斗结束（`endBattle`）不再直接回调 `onEnd`，而是先渲染**结算面板** `#bf-result`（半透蒙层 + 卡片）：
  - 标题（得胜 / 失利 / 撤兵 / 势均力敌）、回合数、双方存活营数。
  - **各营战绩表**：余兵/上限、折损、造成伤害、歼敌（按伤害降序）。
- 点「继续」才触发 `onEnd` 并收起战场；单位战绩由 `applyDamage` 实时累计 `dmgDealt` / `kills` 与 `startCount`。

## 6. 敌方 AI（P1 升级）

`aiAct()` 不再只是「血少先打 / 最近先动」：
1. **目标评分**：残血优先击杀(权重高) → 我克它(+权) → 它克我(−权) → 后排弓弩优先点掉 → 输出效率。
2. **集火 / 绕后**：当前不在射程则枚举「可达格 × 目标」，选能命中且地形最优（攻方站丘增攻、守方站林/营垒减伤）的落点；远程尽量拉开到射程 2 以避免贴脸反击。
3. **低血 / 低军心后撤**：`hp<22%` 或 `morale<28` 且能脱离敌方攻击覆盖时，退向己方出生侧最安全格（`retreatCell`，按地形与敌火覆盖评估）。

## 6. 调参入口（数据层）

- `shared/data/battlefield.js`：`BF_COUNTER` / `BF_COUNTER_MUL` / `BF_TERRAIN` / `BF_FORMATION` / `BF_DMG_COEFF` / `BF_ROUT` / `BF_MOVE` / `BF_RANGE` / `BF_SPAWN` / `BF_GEN_TERRAIN` / `BF_DEFAULT_GRID` / `ARMY_ORDERS` / `moraleBand`。
- `shared/config/constants.js`：`VERSION`（与 `bundle.py` 自动同步，改完跑 `bundle.py` 即可强刷缓存）。

> 注：默认 `BF_MOVE = round(spd/7)`，典型部队(spd 8–20)每回合移动 2–3 格；低 spd 单位仅 1 格，长棋盘前几回合以行军为主，配合「跳帧 + 3×」可快速推进。如需更快接战，调小 `BF_MOVE` 的除数即可。
