# 02 · 玩法与系统

> 本文汇总**当前实装**的系统。带「实测」标记的是本版本真机跑过确认的。

---

## 一、核心循环

```
探索（房间 → 城格 → 郊野 → 城市）
   ↓ 遭遇 / 触发
战斗（回合制）或 事件/剧情
   ↓
获取（战利品 / 修为 / 银两 / 声望）
   ↓
养成（属性 / 武学 / 装备 / 军队 / 领地）
   ↓
推进主线或经营势力
```

---

## 二、时辰与作息（体感的重要来源）

世界按**十二时辰**推进，动作有分钟级耗时。

- **点卯**：卯时到中军场院（苦役营），自动应卯（有固定触发器）
- **销名**：未时后进牢房，牢头在即可销名
- **宵禁 / 更鼓**：夜里行动受限，有巡夜与警告机制
- **跨子夜**：`day + 1`，同时触发 `tickArmyDay`、NPC 流动 `tickDay` 等日结

> 这套机制让"今天该干什么"有真实紧迫感，是本作区别于纯文字游戏的关键。
> 详细的分钟级时间表见 [GAME_DESIGN_全量.md](GAME_DESIGN_全量.md) 1.1.1a 节。

## 三、战斗系统（DQ 式回合制 · 实测）

进入战斗时界面显示：

```
──── 狭路相逢 ────
「苦役营看守」营中官差 拦住去路！
〔行动顺序条：蓝=我方指令，红=敌方意图，数字为出手节奏（越小越快）〕
```

**指令五件套**：

| 指令 | 说明 |
|---|---|
| 普攻 | 主按钮，单敌时**免选目标**直接出招 |
| 招式 | 弹出"胶囊"快捷栏，按武学套路分组（含 军令 组） |
| 防御 | 本回合防御 |
| 道具 | 恢复/暗器，占本次行动 |
| 撤退 | 显示当前成功率（实测 59%），失败会被扣一轮 |

细节：
- 多敌时才弹目标选择；单敌自动锁定（`#app.in-combat` 下由 `dqShowTargets` 处理）
- 有未命中/闪过、暴击等判定（实测日志：`被「营中官差」闪过！（未命中）`、`【暴击！】`）
- 队友参战（存档中有周仓时可见 `周仓使出「崩拳」`）

**战后结算**（实测）：大胜 → ⚔ 修为 +20 / 💰 银两 +8 / ✦ 潜能 +5 / 🏴 声望；有战利品时弹拾取面板，拾完点确认。

> ⚠️ 已知体验问题：战斗结束后会**同时**弹出结算面板与「破境」升级面板（后者盖在上层）。
> 见 [../03-项目状态/02-已知问题.md](../03-项目状态/02-已知问题.md)。

## 四、养成

- **破境升级**：修为达标即进阶 LV，获得自由属性点（可随时在角色面板分配，不必当场）
  实测：第一次脱身时连升 LV.2 → LV.3
- **武学 / 套路**：装配后可战斗使用，按"套路"分组；基础招式如「崩拳」
- **装备**：六槽，`item.stats{atk,def,hp,spd}`；耐久为 0 不计入加成。**武将装备会真实计入其战斗数值**
- **职种差异化**（角色创建时三选一）

| 职种 | 侧重 | 效果 |
|---|---|---|
| 游侠 `youxia` | 交际 | 招降率 ×1.2 |
| 将才 `jiang` | 作战 | 玩家部队攻击 ×1.25 |
| 相才 `xiang` | 经济 | 纳赋/治下城发展 ×1.35 |

- **声望**：分 **凶名 / 义声** 双向（可被 善举/恶举 同时影响），在角色面板查看

## 五、经济

- 通用货币：**银两**
- **钱庄（`shop.js` 的 bank）**：本城存取免费；异地汇兑收"汇水"
  费率 `max(0.02, min(0.20, ceil(li/500)*0.05))`，`li` 走 `LF.ROADS.li(a,b)`
- 商店买卖：点击店铺即进交易面板（**不先弹菜单**，见 06 设计规范）
- 地产：`house_deed` 房契，价格 `200 + grid*60`

---

## 六、军队与战略

- **多军团**：`state.armies` 字典 + `armySel` 指向选中军团；保持 `S().army` 指向选中军团以兼容存量调用
- 补给：驻守己方城就食；行军依托城寨补粮；**断粮会逃兵**
- 军令台顶部可切换/新建军团
- **山河志（战略地图）**：D3 渲染的州郡地图，`ensureStrategicMap` 懒加载三件套（d3 / map_regions / strategic-map），`prefetchStrategicMap` 空闲预取

---

## 七、城市经营

- 城内是网格 **城格** 结构，按功能分坊（官署坊 / 军坊 / 里坊 / 文教坊 / 码头坊）
- **都城**：可 declareCapital，都城中央格为 palace，且配 `OFFICE_DYN` 动态府衙
- **营造**：命令式委任（见 `edicts.js` / `officers.js`），Delegates 监理/民夫/士卒，按月结算产出
- 设施派遣：农场/商号/矿场/工坊 四类，产出走 `facilityOutput`（含 statMul/skill/labor/troops）

> ⚠️ **构建坑**：`city.js` 的 `seedWards` 曾被 terser DCE 删掉，导致所有城市没有 ward 单元。
> 详见 [../01-工作说明/05-恶性Bug与陷阱清单.md](../01-工作说明/05-恶性Bug与陷阱清单.md) P0-b。
