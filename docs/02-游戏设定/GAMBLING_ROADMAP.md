# 赌坊玩法备忘录（GAMBLING ROADMAP）

> 用途：记录「快活赌坊」的已实现与规划玩法，防止迭代遗忘。最后更新：v20261001a。

## 一、现状（v20261001a 已实现）

**店铺**：`shared/core/building.js` → `duguang`（快活赌坊，洛阳）

**已上线玩法：押大押小（掷骰）**
- 窗口：`openModal('gamble')` → `shared/core/gamble.js`
- 流程：输入/快捷押注额 → 押大 or 押小 → 手伸入竹碗（握拳→张开→缩回）→ 三骰掉入碗中转圈 → 停下亮点数 → 结算文案 + 银两变动
- 规则：3 骰和 4~10 为小、11~17 为大（赔率 1:1）；豹子（三骰同面）庄家通吃（押注没收）——庄家优势约 2.8%
- 兜底：余额校验（gold < 押注拒绝）、押注为 0 拒绝、输光提示

**赌坊原保留内容**：骰盆「掷骰一博」（50% 小赌）、「看人下注」、「交谈」；赌徒「交谈」（昼夜不同台词）

## 二、规划中玩法（按优先级）

### P1 · 赌坊江湖味（场所化）
- [ ] **荷官 NPC**：发骰吆喝赔率，进赌坊先见荷官
- [ ] **账房 / 当票**：输光可抵押物品换银（当票机制，过期赎不回 → 物品永久失去）
- [ ] **气氛文案循环**：开局随机起哄台词（「押大押小，落子无悔！」）；连赢 3 局围观叫好、连输 3 局冷嘲
- [ ] **输光保护**：gold < 20 荷官警告；抵押入口

### P2 · 事件与长线
- [ ] **赢钱事件**：单夜赢超 100 → 出赌坊被「眼红客」拦路（可战/可逃）；赢超 300 → 庄家请进**暗局**（高赔率但骰子有诈：掷 3 次选「有诈/无诈」）
- [ ] **称号与风评**：累计胜负 → 风评变「赌徒/散财童子/赌神」，影响 NPC 好感与借钱额度
- [ ] **情报位**：赌徒酒后漏口风（悬赏/秘闻/兵力调动），与已有「打听消息」衔接

### 扩展玩法候选（参考其他游戏）
- [ ] **猜单双 / 猜点数**：押注后猜 3 骰和的单双或具体点数（高赔率低概率）
- [ ] **斗鸡 / 斗蛐蛐**：押注一场随机赛局，赔率 1:2，带气氛描写
- [ ] **樗蒲 / 牌九简化**：古代博戏包装的比点玩法（差异化换皮）
- [ ] **赌桌竞技**：与 NPC 对赌（如与豪杰赌一局，赢了得情报/物品/好感）

## 三、设计铁律（数值与体验约束）
1. **庄家优势 5~10%**：单局可赢、长期必输——刺激但不崩经济
2. **押注分级**：1~100+ 银两级（快捷档 10/30/50/全押）
3. **过程感优先**：骰子动画/文案反馈是核心卖点，不做"纯随机判定"
4. **虚拟货币**：仅银两，无现实金钱映射
5. **风评联动**：赌博影响名声，与已有侠义/凶名系统衔接
