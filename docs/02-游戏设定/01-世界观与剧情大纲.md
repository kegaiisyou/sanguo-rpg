# 01 · 世界观与剧情大纲

> 本文是**精简版导航**，聚焦已实现/已验证的剧情结构。
> 完整世界观设定（四层社会结构、资源三轨、九大门派等）见 [GAME_DESIGN_全量.md](GAME_DESIGN_全量.md)。

---

## 一、时代背景

- **时间**：东汉光和年间（黄巾之乱前夕/初期），汉室衰微、宦官外戚相争、太平道暗流涌动。
- **基调**：武侠 + 乱世求生。玩家从最底层（苦役）起步，而非天生的英雄。
- **地理**：以真实州郡为骨架（当前覆盖数十座城池与多段郊野），每城各有自己的城格布局与若干城门方向。

> 术语纪律：文案统一走"时代语汇"（详见 GAME_DESIGN 全量文档 1.1.2 节），避免现代词混入。

## 二、主线流程（开场 → 毕业）

这是**所有玩家都会走到的共同段**。

```
捏人（角色创建）
   ↓ 职种三选：游侠 youxia / 将才 jiang / 相才 xiang
序章演出
   ↓
沦为苦役 → 苦役营 kuyilao（新手教学区）
   ↓
第 4 日「夺营」事件
   ↓ 四选一分支
逃出 → 林径 lindao → 大世界（近郭 / 黑山寨 / 白檀军屯…）
```

### 苦役营（新手教学区）

这是整个游戏的引导区，也是本版本内容最完整的部分。

核心机制：
- **点卯**：卯时到中军场院 `(1,1)`（坐标在中军广场。注意营区是**一个房间内的网格**，格间移动不触发 `onEnter`，见下）
- **劳作 / 任务**：主线为「逃出苦役营」
- **仓吏补给站**：可领物资
- **回牢销名**：未时后进牢房，牢头在即可销名
- **宵禁 / 更鼓**：夜里行动受限
- **教学战斗**：韩铁教你「普攻 / 防御 / 道具」三式，打赢即毕业这条教学线

> 触发坑提示：苦役营的岗哨、牢房、中军**都属于同一房间 `kuyilao`**（营区网格）。
> 所以格间来回走**不会**触发房间的 `onEnter`。要触发夺营，得真正离开营区再回来，
> 或用调试桥接 `window.checkTriggers({hook:'onEnter', room:'kuyilao'})`。

## 三、第 4 日 · 夺营事件（核心分岔）

条件：第 4 日（内部 `day >= 3`）、已出牢、进入中军场院时裁决。

太平道起事夺营，玩家据此脱身。**四个分支**：

| 分支 | key | 说明 | 状态 |
|---|---|---|---|
| 送信搬救兵 | `officer_letter` | 电影化分支 | 已有 |
| 默叔线 | `moshu` | 电影化分支 | 已有 |
| 阿禾线 | `minor_ahe` | 电影化分支 | 已补全 |
| **孤身** | `minor` | 无牵绊者走此线，打一场即可脱身 | 已补全 |

### 孤身分支（`minor`）本轮实测路径

```
中军场院触发 → 出现选项：
   ①〔颔首〕静待时机   ②〔佯降〕假意归顺   ③〔强突〕径扑营门
   ↓ 选①
夺营起爆 → 与「营中官差 / 苦役营看守」发生战斗
   ↓ 打赢
逃出 → 林径 lindao（flags.coup.minor_escaped = true）
   ↓
战斗结算（大胜：修为/银两/潜能）→「破境」升级弹窗 → 恭喜教学完成
   ↓
任务「逃出苦役营」达成（+200 修为）→ 教学完成，进入自由的大世界
```

> 实测备注：战斗胜利后会**同时**弹出结算面板与「破境」升级面板（后者压在上层）。
> 以及从战斗结束到可自由操作要点掉约 14 段叙事（>20 秒），期间按钮全锁 —— 详见 [../03-项目状态/02-已知问题.md](../03-项目状态/02-已知问题.md)。

## 四、大世界（毕业后）

逃出后抵达 **林径 `lindao`**，从这里开始是开放玩法：

- 可见 NPC：行脚货郎、受伤猎户
- 出口方向：黑山寨·寨门（↑）、近郭（←/→/↓）
- 面板点亮：角色 / 行囊 / 军队 / 任务 / 山河 / 设置

后续路线参考：往林径寻货郎，或北去**白檀军屯**安顿身心，再作打算。
