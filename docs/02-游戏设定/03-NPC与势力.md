# 03 · NPC 与势力

> NPC 是本作内容密度最高的系统之一。完整机制在共享记忆里有更细的记录，本文汇总要点。

## 一、NPC 分两大类

### 1）功能性 / 剧情 NPC（固定）

写在房间定义里的常驻角色，推动教学与主线：

| 角色 | 出现处 | 作用 |
|---|---|---|
| **韩铁** | 苦役营 | 新手战斗教学（普攻/防御/道具三式） |
| **牢头** | 牢房 | 未时后可销名 |
| **仓吏** | 补给站 | 领物资 |
| **崔九** | 夺营链 | 剧情推动者 |
| **行脚货郎** | 林径等 | 交易 ⚠️（见下方已知问题） |
| **受伤猎户** | 林径 | — |

> `rooms.js` 里给房间加交互物件时，**动作函数只能调用已挂 `window` 的引擎函数**（闭包作用域限制）。详见 [../01-工作说明/04-代码架构与模块约定.md](../01-工作说明/04-代码架构与模块约定.md)。

### 2）历史名将（`shared/data/officers.js`，共 50 人）

由 `npcai.js` 动态投放到城市街市 / 郊野，让玩家能在市井上撞见名将。

## 二、名将的「内驱力」六维

`yi` 义理 / `xin` 野心 / `mian` 面子 / `cai` 财欲 / `wu` 好武 / `jiu` 嗜酒

**判定顺序**：数据里显式写了 `drive` 则优先使用；否则从五维 + tags / bio / title 关键词推导。

实测推导效果（未手填数据）：
- 刘备 → 义理 79
- 张飞 → 好武 78
- 曹操 → 野心 80
- 郭嘉 → 嗜酒（史实梗命中）

**落格**：按首要内驱力挑城市格型 ——
`wu`→drill/barracks、`jiu`→market、`xin`→gov/command、`cai`→market、`yi`→market/resid、`mian`→resid/gov
（用 `hash(id)` 在同型格稳定选一格，同人同日只落一处，不分身。）

**实测城市分布**：
涿县=刘备/关羽/张飞 · 洛阳=董卓/吕布/华雄 · 许昌=曹操/郭嘉/典韦 · 成都=刘璋/法正/张松

### ⚠️ 两个已知的"看起来该发生但不会发生"

1. **50 位名将无一人以「面子」为首要内驱力**（mian 公式偏低，总被 yi/xin/wu 压过）。
   → 所以"挂靠面子"的内容永远不会触发。**倾向面子的玩法要改判据**（如 `mian >= 40` 给概率）。
2. **张飞不会主动要酒**：其 bio（"喝断当阳桥…万人之敌"）不含酒字，纯推导会判成好武 → 讨兵刃。
   → 已在 `officers.js` 给他加**显式 drive** `{wu:85, jiu:90, ...}`，现已会去市集酒肆、委托变成「讨一壶酒」。

## 三、名将流动与偶遇

- **位置** `placeOf`：`flags.npcTravel[id]` > `t.timeline[年份]` > `t.home`
- **每日流动** `tickDay()`：接在 `tickArmyDay` 之后。用**月倾向 ÷ 30** 得日概率（曾误把月倾向当日概率 → 40 天移动 648 人次、涿县空城）；抵达后安居期 30~120 天；非野心/好武者只就近流动（≤600 里）。
- **郊野偶遇** `famousInField(room)`：概率 `wu .50 / jiu .35 / xin .25 / cai .20 / yi .15 / mian .10`。实测 392 片城郊中 55 片能遇名将（名将只有 50 人，覆盖率本就有限）。

---

## 四、名将委托

按内驱力给不同委托，需求只用**真实存在的道具**（`items.js`：jiu 黍酒 / gumao 骨矛 / dou 菽豆 / house_deed 房契）或银两。

实测闭环：
- 刘备[义理] → 济民之粮（3×菽豆）
- 张飞 → 讨一壶酒
- 曹操[野心] → 资助起事（300 两）

状态流：**none → taken → ready → done**，交付后回赠（gold 型回赠 = 本额×0.8 + 声望×20）。

## 五、地产 / 房契

- `items.js` 的 `house_deed`（凭证类）
- `estatePrice(cid) = 200 + grid*60`（涿县 500 / 洛阳 740）
- 购买写 `flags.properties[cid]`
- 牙人（房产中介 NPC）挂在 `resid` 或 `market` 格

## 六、势力与外交（简述）

- 城市归属势力，`flags.diplo[fid] = {status:'war'|'truce'|'alliance', until:月序}`
- 议和 💰50 / 声望 10 / 3 个月；结盟 💰200 / 声望 30 / 9 个月
- 招降率 `p = 0.30 + rep/200*0.5 + (favorMul-1)*0.4 - min(0.5, power/120)`，夹在 [0.05, 0.95]
- 汉室 `han` 与己方 `player` 不参与外交

详见 [../02-游戏设定/02-玩法与系统.md](../02-游戏设定/02-玩法与系统.md)。
