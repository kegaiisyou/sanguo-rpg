## 〇、为什么只要 12 张（内部说明，可不发给豆包）

静态扫全仓库会得到「64 种物品 emoji 未映射 / 94 种非物品符号未映射」，但那是**假缺口**：绝大多数物品已有独立 `items48` 图，符号也多出现在按钮文字里而非图标位。

`v20261113e` 用 Playwright 真机（1280×820 + 390×780 双视口）逐个打开 36 个面板后实测：

- 破图 / HTTP 4xx：**0**（3 张缺失 PNG 已用同风格现有图临时兜底）
- 因「无图无映射」而真的露出彩色 emoji 的格子：**只有 9 个物品**
- 其余 28 个无独立图的物品已被水墨 PNG 兜底覆盖，无需出图

所以本批 = **3 张语义修正图 + 9 张物品独立图 = 12 张**。不要按 58 张 / 94 张去做。

## 一、本批总规范（两系列尺寸不同，务必分开）

| | A 系列 · 通用图标 | B 系列 · 物品图标 |
|---|---|---|
| 数量 | 3 张 | 9 张 |
| 交付尺寸 | **96 × 96 px** | **128 × 128 px** |
| 格式 | PNG，**RGBA 透明底** | PNG，**RGBA 透明底** |
| 存放目录 | `icons96/` | `items128/` |
| 文件名 | **中文名.png**（见下表） | **小写英文 id.png**（见下表） |

### 画风（两系列完全一致）

- 中国**淡墨线描**，透明底，**不要纸底、不要不透明背景、不要圆形徽章底、不要外框**。
- 墨色以深褐黑为主，可极少量赭石 / 朱砂点缀，但**全 12 张必须同一套配色和线宽**。
- 单张单主体，居中，主体占画幅 **70–80%**，四周留 10–15% 全透明边距。
- 线条要粗：128px 下主线 3–4px，**不要细于 2px**；缩到 16–24px 显示时仍能一眼认出是什么。
- 统一 3/4 视角或正视，勿混用；无投影、无渐变、无高光、无背景纹理。
- **纯线描 + 少量平涂即可**，不要写实、不要厚涂、不要 3D 渲染感。

### 时代与禁用（最容易出错，请逐条遵守）

- 时代：**东汉末 / 三国**。器物用木、陶、竹、青铜、麻布、纸卷。
- **禁止出现**：塔吊、脚手架、公文包、西装、玻璃罐、塑料、拉链、螺丝、电池、灯泡、现代书籍装帧、印刷体文字、阿拉伯数字、水印、二维码。
- **不要在图里写任何字**（含印章字、标签字）。
- 不要现代卡通表情、不要 Q 版、不要拟人化。

### 交付方式

- 打成 zip，内含 `icons96/` 与 `items128/` 两个子目录，**一张图一个 PNG**。
- 不要拼图 / contact sheet / 长图；不要带 `(1)(2)` 编号。若工具自动生成编号，请附一份「编号 ↔ 文件名」对照表。
- 分辨率就按 96 / 128 出，不要给 1536 母版（这批是线描小图，放大反而失真）。

## 四、明确不要做（避免白做）

- **纯色圆点 / 几何符**：🔴 🟢 🟤 ⚪ ⚫ 🟦 🟨 🟫 ◆ ◈ ◎ △ ◇ —— 这些是品质 / 状态色标，由 CSS 处理，不出图。
- **UI 符号**：✕ ↓ ✓ 👤 —— 关闭 / 箭头 / 勾选 / 头像占位，不出图。
- **按钮文字里的 emoji**（如 ⚔ 出兵、🔍 搜索、⛏ 采矿、🔨 打造、💰 钱、📍 定位、🪣 水桶、🌱 种子）：这些已有对应水墨图标，我会补映射复用，**不需要新画**。
- **已有图的物品**：全库已有 135 张通用图标 + 231 张物品图标，除上表 9 项外都不要重画。
- **立绘 / 头像 / 门派徽记 / 敌人立绘**：属另外几批规格（不透明纸底、半身浓墨、240×240 起），**不要混进本批**。
