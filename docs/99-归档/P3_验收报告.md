## 三、本轮修复的真实缺陷

- **城门哨格无法出城**（`shared/core/engine.js` 的 `move()`）：`currentRoomExits` 与 `leave_city` 都对「城门格 `gate`」和「岗哨格 `sentry`」渲染/处理出城，但 `move()` 只认 `gate`。苦役营南门恰是 `sentry` 格（`layoutGrid` 第 3 行中列），点底部「出城」会落到城内网格移动分支 → 越界 → 只报「此处无路可去」，导致囚籍规条（未脱籍出营被官差拦）**根本走不到**。已统一为 `_ct===gate || _ct===sentry`。
- **出营三叙被下一场景清空**（`shared/core/engine.js` 的 `finishEscape()` + `shared/core/triggers.js` 的 `graduate()`）：`renderRoom()` 开头的 `flushNarr()` 会丢弃「上一场景排队中/打字中」的文字，而旧序是「先 log 出营文案 → 再 moveToOutside()」，于是〔脱籍〕〔密道线·逃脱〕〔教学完成〕三段常被整段清掉，玩家看不到逃脱文案与出营引导。已改为：`graduate(true)` 只做状态交接（移除 onb 界面 / 解锁菜单），三段文案一律在 `moveToOutside()` 落位之后输出。
