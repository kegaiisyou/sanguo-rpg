## 〇、先回答你的核心疑问

### 1）目前军队操作会不会很麻烦？

**比《骑马与砍刀》轻很多，但仍有"多步跳转 + 手动后勤"的繁琐感，且目前是"单支军队"模型而非多军团编队。**

当前军队（`army.js`）已经把所有操作**集中到一个"军令台"模态面板**里，不是 M&B 那种实时手操，这点是对的。但麻烦点在：

| 操作 | 现状 | 痛点 |
|---|---|---|
| 募兵 | 必须**身在本方军营格**才会解锁；每城有兵源上限（pop×2）；跨城募兵要反复移动进场 | 没有"本国境内就地征兵 / 行营" |
| 编阵 | 前军/中军/后军/游骑，逐兵种点"改列" | 可接受，但缺"一键布阵模板" |
| 辎重/军粮 | 容量上限、需从背包手动存/取、出征预支粮草 | 对轻度玩家偏繁琐 |
| 调兵 / 出征 | `调兵遣将` = **整支军队搬家**到某城（按里程算天数）→ 再到政令台宣战 `warlordBattle` → 攻城战 | 没有"分兵驻守多城 / 前线补给线 / 一键出征向导" |
| 宿营/斥候/设伏 | 按钮齐全，但都是单步手动 | 缺"委托自动巡逻/自动整军" |

**结论**：你设想的"像 M&B 那样精细控制军队"，目前只能说**半满足**——有战前布阵、兵种阵位、出征、单挑，但底层是"一支军队 + 军令台"，没有多军团、没有补给线、后勤偏手搓。

### 2）你规划的形态（RTK10 + M&B + 自动化派遣）是否可行？

**组合成立，且与现有代码基底契合度很高**，但要清楚一个张力：

- RTK10 的"培养 + 战略 + 城镇经营"——**已基本具备骨架**（武将任命太守/主将、战略图、外交、月份结算、事件）。
- M&B 的"精细控制"——**应理解为"战前布阵 + 军令抉择 + 兵种克制"**，而不是实时战术操控。强行移植实时手操会和"文字载体"冲突，体验反而割裂。
- **最大的缺口是你的 Factorio 式设想**：把文官/武将派驻到"矿场 / 工坊 / 农庄 / 商号"去**批量自动产出**，按属性 + 兵种 + 士兵数决定速率。当前系统**只有"太守 / 主将"两个任命位**，根本没有一个"设施派遣层"。这是你这套设计里最能拉开体验差异、也最该优先补的部分。

## 一、目前游戏的游玩方式（现状映射）

**一句话**：纯文字、时辰/日历驱动的开放世界 RPG。核心循环是 `探索/事件/战斗 → 数值成长 → 解锁新区域与系统`，玩家既能手动操作、也能靠"任命武将"让系统自动化产出。

- **载体**：网页 H5 单端，`index.html` + `shared/`（UMD 单一数据源）。无图形，文字即美术。
- **时代**：开局光和六年（183），时间随游玩流动至中平/三国；历史事件（黄巾/讨董等）按时间线到来的判定系统**待做（P7）**。
- **出生与地图**：北疆幽州·燕山山口起步 → 颍川早期可玩区（剿匪/斩华雄）→ 声望解锁洛阳 → 长期开放世界。山河志用 D3 真实地理战略图（州/郡/城/势力分层 + 两级 LOD）。
- **战斗**：半手动回合制（普攻/技能/道具/防御/撤退），13 武器艺线 + 内力 + 战意槽；攻城触发阵前单挑、外交面板可舌战说降。
- **经营**：图纸→工地→分阶搭建→落成（冶炼工坊：炉膛烧铁 + 铁器打造）；物资合成配方台。
- **内政/战略**：太守影响税务/治安/农商产出、主将影响统率（**已真正接入月度结算**）；势力外交（议和/结盟/招降）；朔日月份结算（纳赋/势力 AI/存亡/统一终局）；月度随机事件剧本。
- **武将**：结义/敌对相性（影响忠诚浮动、临战协同、士气），登庸/任命/解职。

## 四、需要增加的功能（对齐你的设想）

> 优先级高的排在前面，标注 🔴 为与你"自动化派遣"核心设想强相关。

1. 🔴 **设施派遣层（核心缺口）**：把文官/武将派驻到 `矿场 / 工坊 / 农庄 / 商号 / 学馆` 等**设施**，按 `属性（政/魅/智）+ 兵种 + 携兵数` 决定**批量产出速率**；可设"产出日志 / 设施进度条 / 离线累积"。这是 Factorio 类比的落点，也是与 RTK10 最大的差异化。
2. 🔴 **多军团编队 + 补给线**：从"单支军队搬家"升级为"多军团、分兵驻守、前线补给、军团调度沙盘"。
3. **战前军令沙盘**：布阵预览、兵种克制、火攻/火牛/伏兵/劫粮等战术指令（让"精细控制"落在战前而非实时）。
4. **军团 AI / 委托出征**：挂机推图、自动补给、自动整军（给"懒得手操"的玩家）。
5. **武将相性/忠诚可视化 + 事件**：F1 底层已做，需把"结义/敌对/忠诚"在武将面板直观呈现，并接入剧情事件（背叛/效死/离间）。
6. **城镇经营深度**：商业/农业/治安三条线独立发展，叠加灾害、流民、商路事件（F4 已有雏形可扩展）。
7. **门派系统 UI 接入**：数据层 3 派已就绪，补门派任务线、传功、转投界面。
8. **豪杰结交 / 招募入队**：刘关张、典韦、太史慈等入队（设计已提"待讨论"，建议落地）。
9. **经济系统**：黑市物价波动、钱庄、镖局（与豪商层联动）。
10. **历史事件触发判定（P7）**：黄巾/讨董按时间线到来，且受玩家选择影响（不发生/延后/分支）+ 纪元切换。
11. **成就 / 图鉴**：部曲图鉴、武学图鉴、势力图谱。
12. **快速行军 / 时间加速**：战略地图一键行军、委托推进开关，缓解"手动经历每个时辰"的慢。

## 五、目前不够好、需要优化的点

1. **军队后勤繁琐（最该优化）**：补"自动补给 / 一键整军 / 出征向导"；募兵放宽到"本国境内就地征兵或行营"，不必每次钻军营格。
2. **内政派遣"无体感"**：太守/主将任命后只改月度数字，玩家看不到过程。加"设施产出进度条 / 派遣日志 / 任期面板"，让自动化有反馈（这也正好服务上面的设施派遣层）。
3. **战略图与 RPG 地图割裂**：山河志点击只作参考不传送。可用"派遣军团自动行军 / 任命太守后城池在战略图高亮"来桥接两层。
4. **单挑/舌战入口单一**：只在攻城触发。加"阵前挑战""说客出使"等独立玩法，让 F3 更常用。
5. **武将面板信息密度低**：相性、忠诚、派遣状态未直观呈现，建议一屏看全（含关系网小图）。
6. **时间流速偏慢**：手动经历每个时辰对"战略推演"节奏拖。加"加速 / 委托推进 / 跳过闲时"开关。
7. **长途移动点击多**：郊野逐格 + 分钟制，建议战略图"一键行军" + 设伏/扎营自动触发。
8. **事件剧本偏静态**：5 个事件且与武将/势力联动弱。扩展事件池并接入相性/忠诚/势力关系，让 F4 真正"剧本化"。
9. **新手指引不足**：系统多、入口散，首个小时的引导（捏人后该去哪、先做什么）可更顺。
10. **战役/主线方向感弱**：当前主线是"演示循环"，长期开放世界需更清晰的目标阶梯与章节节点。

## 六、给你的落地建议（顺序）

- **第一步（最值）**：做"设施派遣层"（第 1 条）+ 内政派遣体感化（优化 2）。这直接落地你 Factorio 式设想，且能复用已有 `governorOf/taxBonus/yieldBonus` 等接口，成本可控、体验增量最大。
- **第二步**：军队后勤便捷化 + 多军团/补给线雏形（优化 1 + 第 2 条），让"精细控制军队"成立。
- **第三步**：武将相性/忠诚 UI + 事件联动（第 5 条 + 优化 8），把 F1/F4 连成"人物关系驱动叙事"。
- **第四步**：门派 UI、招募入队、经济、历史事件判定（P7）等长线内容。

> 一句话总结：**你的形态完全可行，现有代码已铺好 70% 的地基；真正的"胜负手"是补上"设施派遣自动化"这一层，并让军队从"单军团手搓后勤"升级为"多军团 + 战前军令沙盘 + 委托挂机"。**
