## 一、为什么要重写

| 症状 | 根因 | 对策 |
|---|---|---|
| 为教而教的孤立点击 | 目标链是「解锁页签 → 点一下 → 再解锁下一个」的清单式教学 | 改为**一条生存主线**驱动 |
| 大量重复操作 | 劳作闭环跑满 3 工，3 次循环无剧情增量 | 3 次各挂剧情，第 2/3 次可跳过（§7） |
| 无意义演绎 | 「环顾四周」是纯信息播报，且描述的是不存在的塌墙根 | 废弃，去路改由**牢头带路**在剧情里交代（§6 ④） |
| 剧情与地图脱节 | 塌墙根/密道不在九宫格内 | 全部动线落回九宫格真实场景 |
| 预言式 NPC / AI 味台词 | 角色直接点破结局、说抽象套话 | 角色只讲古、留半句，教训由玩家自悟（§6·周听涛准则） |
| 取物无实感 | 交互一下物品即入包 | 改容器式取物（§11） |
| 仓库无门槛 | 存取面板完全开放 | 加苦役身份权限（§12） |

## 二、设计原则

1. **剧情串联优先**：每个教学动作都回答「我为什么要按这个」。
2. **动作即有回响**：每做一步，世界里有人看见、有反应。
3. **一次只教一件事**，解锁理由编进剧情。
4. **每个场景都要有实体**：教程用到哪格，那格必须有可进入的房间或可交互的场景物件，不能只有一个按钮（§9）。
5. **角色多样、戏剧冲突**：苦役营只是"不得不做"的驱动力来源，张力来自徭役制度的压迫（§14），而非越狱爽文。
6. **不预言、只造境**：NPC 用典故与星象营造氛围，不直接点破主角命运（§6·周听涛准则）。

**贯穿钩子**：周听涛隔栅念的一句古谶——开场第一个悬念，第 4 日夺营回收。

### 5.1 点卯策略：首次手动、其后自动

- **首次**：`flags.onb.rollManuallyDone` 未置时，目标链指向「验名」，必须玩家亲手点（`laotou_corridor`/`autoOnbRoutines` 在首日到点时不自动替点，给一行提示「把总摊着名册，你上前应个名」）。点过一次后置 `rollManuallyDone=true`，并把营规立住。
- **其后**：`autoOnbRoutines` 到点自动点卯（沿用现有 `roll_call` 机制），销名/晚归时仅给一行提示，不再强制交互。
- 理由：全程自动玩家不知有"点卯"，教程缺了理解营规的机会；全程手动则第 2、3 日重复变烦。折中既教规则又不扰民。

### 周听涛台词准则（落地到 `dialogues.js`）

1. **只讲古、不讲主角**：可引秦汉及更早（春秋战国、秦、西汉）典故与星象术语；**三国是后世，禁止**。
2. **留半句、不点破**：用星象术语（荧惑守心、枉矢流星、紫微晦、天狼明）与古谶营造氛围，不把"你会如何"说出口。
3. **不置命运 flag、不触发机制性 buff/debuff**：纯氛围，代价只体现在台词里（如"老夫多嘴了""泄露天机是要折寿的"一句自嘲），不落实际系统。
4. **改 `dialogues.js` 内 `v20260912a` 旧注释**：原注释以"讲三国/战国=后世视角"为由删光讲古台词；纠正为"战国/秦汉是前代可讲，唯三国不可"，避免后人误删。

## 七、劳作闭环的「去重复」设计

原设计：装担 → 卸料 ×3，三次完全一样。改为**三次各挂剧情增量**，第 2/3 次可跳过：

| 趟次 | 剧情增量 | 可跳过 |

| 1 | 学装担/卸料。牢头记账：「记一工。」（定性旁白："城旦之役，一工既成。"） | 否（教学必经） |

## 十、对话分段规范（全游戏通用，本轮重点）

1. NPC 台词数组**按句拆**，说话人**每段重复署名**（见 §6 开头牢头示例）。
2. 单段不超过两个短句；信息密度高的台词用多段铺陈，而非一整段。
3. 玩家选项（`asks`）也拆短，避免一长串。
4. 旁白（`log`）同理：长旁白拆行，节奏与台词一致。

## 十二、仓库存取权限（苦役身份）

**现状**：`storage.js` 搜索 `权限|perm|accessLevel|readonly|locked` **零匹配**，面板 `Shop.openShop(cid,'storage')` 对玩家完全开放。

**设计**：

1. 玩家在营中身份为苦役（`flags.onb` 存在即视为囚籍）。仓库分两层：
   - **卸料台暂存**：教程期开放，仅能存取"石料/木料"类（劳作产物），无需许可。
   - **公库**（粮秣、兵甲、杂物）：平日上锁，**需仓吏郑刚（(2,1)）许可或好感 ≥1** 方可开启。
2. **校验前置**：在 `openModal('storage')` 之前判定身份/好感，不通过则弹提示「郑刚把库门一锁：『没将令，闲人免进。』」并拦截，**不要先渲染再拦截**（避免闪屏）。
3. 教程第 10 步"木片换饭"走的是**伙房**而非公库，不受影响；卸料台暂存保证劳作闭环可走通。

## 十三、军营剧情与任务（(0,2) 军营）

教程期开放营造线，呼应"征发徭役"主题：

1. **修筑营造**：营栅（立木为栅）、**鹿角拒马**、壕堑——在 `construction.js` 的可建项中加入这几类，玩家可"出役"修筑（耗时/耗精力，记工分，顺带学营造系统）。
   - 鹿角/拒马/壕堑均有考据（见 §14），非凭空捏造。
2. **结交军官**：军营置一名军官 NPC（可与韩铁线互文——韩铁在演武场，军营另设营尉），通过"助其整备军械/送信"结好感。
3. **送信**：作为 `officer_letter` 分支的提前铺垫——军官（或韩铁）在营中先托你递个口信，教玩家"信+符信"机制（§14），第 4 日才升级为搬救兵密令。
4. **夜巡打更**：接入 `刁斗` 考据（§14），让玩家体验"戌时后营中巡更"的压迫感（可选小任务）。

## 十七、结交如何成为结局选择器（无需周听涛点名）

- 三条毕业分支（送信/默叔/阿禾）的钥匙是韩铁/默叔/阿禾的好感，**玩家跟谁结交，第 4 日走哪条结局**。人际经营直接兑现成结局，而非孤立堆好感。
- 这个"为什么"由**角色自身递出钩子**（§6 ⑩）：韩铁主动邀你学艺、阿禾怯怯分粥、默叔在你替他挨鞭时认你。玩家在互动中自然理解"这些人能拉我一把"。
- 三人分处两格（默叔/阿禾在牢房 (1,0)，韩铁在演武场 (2,2)），间接带玩家走遍地图，走图由剧情驱动而非目标条硬拽。
- 周听涛**只负责氛围**（古谶、星象），把"你会遇到能救你的人"这个暗示，用陈胜吴广"失期当斩"的旧事**讲给玩家自己听**，而非替你列名单。
