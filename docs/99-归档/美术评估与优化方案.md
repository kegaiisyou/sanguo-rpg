## 二、玩家视角评价

**做得好（会留住玩家的）：**

1. **风格选型正确**。三国题材配水墨静物+暖褐 UI，氛围统一，一眼有辨识度，不是"套皮手游"的塑料感。
2. **暗底对比扎实**。正文、面板、图标在暗底上可读性高，手机小屏长时间游玩不累。
3. **动物/食物类图标有温度**。小羊、小猪、鸡蛋这类手绘感强的图标是全库质量上限，玩家拾取时有"开盲盒"的小惊喜。

**扎眼（会劝退玩家的）：**

1. **白洞残图（本次核心 bug）**。锯框内一大块白、桶口白椭圆、镯心白圆——在暗底 UI 上像"烧穿了一个洞"，是最伤质感的缺陷。最严重的一张（精石锯）白洞占物体像素 56%。修复前这类图标给玩家的潜台词是"这游戏没打磨"。
2. **风格断裂**。打开背包：一半是水墨 PNG，一半是 emoji（🪓⛏️🧪）。玩家会明确感到"做到一半"。emoji 在水墨语境里尤其突兀。
3. **抠图白晕**。多张图标轮廓有一圈泛白描边（白底抠图残留），暗底上像给物体描了圈白粉笔线。比白洞轻，但同样拉低质感。
4. **48px 下细节糊**。麦、药草、种子类图标线条过密，缩小后糊成一团，辨识度低——玩家在背包快速扫视时靠形状认物品，糊=认不出。

**主观打分（满分 10）：** 风格统一性 7 ｜ 图标质量 4→6（修复后）｜ UI 可读性 8 ｜ 氛围沉浸 7 ｜ 综合 **6.5**——上限高，被执行细节拖累。

## 三、制作组视角：根因与优化方案

### 根因分析（本次白洞 bug）

- 图标生产管线是「AI 生成（白底）→ 抠图去背」。抠图算法只处理**与画布边缘连通**的背景，锯框内、桶口内、镯心、犁架内这类**被物体完全包围的封闭区域**不属于"边缘连通背景"，被原样保留成不透明白色。
- 项目 UI 是暗底，白色残洞对比度拉满，成为最显眼的品质缺陷。
- 次生问题：图标 URL 无版本参数，PNG 更新后 CDN/浏览器缓存会让玩家继续看到旧图。

### 已落地（本批次 v20261003b）

1. **16 张图标修复**：连通域 flood-fill 判定「被不透明物体完全包围的平坦纯白」→ 置为透明，共清除 28,368px。
   - 锯类 6 张（mujv/tiejv/tongjv/cutie_jv/bailian_jv/jingshi_jv）
   - 木桶（桶口）、手镯（环心）、木犁（犁架）
   - 农具部件间隙 7 张（tiechu/tiechan/luoyang_chan/bailian_chu/jingmu_chu/jingshi_fu/jingshi_lian）
2. **白名单人工核对**：小羊、鸡蛋、珍珠、面粉、小猪、钓竿等"白色=物体本色"的图标逐一目检后**排除**在清理外，避免把物体清成镂空。
3. **缓存治理**：`engine.js` 与 `uiicons.js` 所有图标 URL 追加 `?v=版本号`，资产更新即时生效。
4. 版本号对齐：bundle.py/constants.js/index.html（bundle?v + game.css?v）→ 20261003b。

### 优化方案（按优先级）

**P0 · 管线固化（防复发，1 天）**

1. 将本次修复逻辑固化为 `tools/icon_postprocess.py`（封闭白洞清除 + 白名单机制），**入库门禁**：任何新图标必须过一遍该脚本再提交。
2. **白晕治理**：对边缘半透明像素做"色值向物体收缩 + alpha 重映射"（等效 erode 1px + 去白），消灭暗底上的白描边。这一步对观感提升最大。
3. 雪碧图改为**构建期生成**：`items.webp/scenes.webp` 从 items48/scene48 自动打包（挂进 bundle.py 或独立脚本），消灭"双真相源改一漏一"。

**P1 · 一致性（消除风格断裂，分批）**

4. **补齐 emoji→PNG**：items.js 中兵刃/工具/药剂三类仍是 emoji 且使用频率最高，按「出场频率×获取场景」排序分批补 48px 水墨图标，每批 20~30 张，风格对齐现有水墨套（统一 128px 源、左上光源、描边粗细）。
5. **图标规范入册**：在 `docs/DESIGN_SYSTEM.md` 增补 icon 章节（源尺寸/光源/描边/禁用纯白填充/封闭区域处理要求），AI 生成时直接作提示词约束，从源头减少洞和晕。
6. **小尺寸可读性**：线条过密的图标（麦/药草/种子）重绘时减细节、加主体占比（主体占画布 ≥70%），以 48px 实际显示尺寸验收。

**P2 · 表现升级（增色，可选）**

7. **品质可视化**：`.packcell` 按 quality（white/green/…）加品质色细边或角标，替代目前纯文字/无提示。
8. **稀有度动效**：绿品以上图标 CSS 微呼吸光（仅 transform/opacity，移动端耗电可控）。
9. NPC 头像库扩容：目前 26 张覆盖不足，程序生成 NPC 走 role 模板已可接受，名将建议逐步补齐专属胸像。

### 验收标准（给后续批次）

- 全量图标扫描报告：封闭白洞 = 0（`tools/icon_postprocess.py --check` 可作 CI 门禁）。
- 抽样目检 20 张：无白晕、48px 下主体可辨识。
- 背包页截图自查：无 emoji 与 PNG 混排的高频物品。
