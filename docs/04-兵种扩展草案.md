# 04 · 兵种扩展草案（A 类 · 形象差异化优先）

> 状态：**方案讨论稿**，未执行。数值/具体兵种待用户拍板后，再出豆包制作要求 + 注册 `troops.js`。
> 原则：本轮只扩 **形象差异大、且能无缝接入现有 6 阵位** 的 A 类兵种；不引入需大改引擎的机制（火伤/踩踏为轻量 flag，几行判定即可）。

---

## 背景

`shared/data/troops.js` 的 `LF.TROOPS` 共 13 种，覆盖 6 阵位（步/远/骑/械/辅/枢），是完整战术集。本轮按用户要求先扩 A 类三种群，重点在**视觉辨识度**而非数值深度：

- 藤甲兵（步）
- 象兵（骑）
- 太平道特殊军队（黄巾系）

---

## 一、藤甲兵

| 项 | 内容 |
|---|---|
| 阵位 | 步（前/中） |
| 形象 | 全身藤甲（藤条 + 生牛皮编织，土黄/藤褐色，**无金属反光**），配藤牌/藤盾。与铁甲步卒（刀盾/长枪）一眼可辨 |
| 机制 | **高物防、惧火**：加 `weakFire:true`，战斗结算火伤 ×1.6。呼应火矢手（全游戏唯一火攻），形成「火矢手克藤甲」的克制链 |
| 数值草拟 | atk 6 / def 14（步最高）/ hp 28 / spd 12 / cost 2 / upkeep 2 |
| desc | 藤甲蔽身，刀枪难入；唯惧火攻 |
| 立绘 | 1 张半身（藤甲 + 藤牌特写），藤色可微彩、其余纯墨 |

---

## 二、象兵

| 项 | 内容 |
|---|---|
| 阵位 | 骑（游骑）—— 先用「骑」复用骑兵逻辑；若体积感需要，可后续新设「巨」阵位 |
| 形象 | 南方巨象 + 象奴（或披甲象），体积巨大，**明显区别于马骑**。裁切保留象头 + 象奴上身 |
| 机制 | **超高 HP、踩踏（对步/辅额外伤害）、缓慢、畏床弩与火**：加 `trample:true`（对 slot 步/辅伤害 ×1.5）、`weakFire`、`weakSiege` |
| 数值草拟 | atk 16 / def 10 / hp 60 / spd 9 / cost 4 / upkeep 4 |
| desc | 南中巨象，踏阵如摧；迟缓畏弩火 |
| 立绘 | 1 张半身（象头 + 象奴，体现巨兽；象鼻/象牙入画） |

---

## 三、太平道特殊军队（黄巾系）

太平道为张角门派（`shared/story/sects.js`）。候选子集，**待用户拍板具体取哪几个**：

| 候选 | 形象差异 | 机制成本 |
|---|---|---|
| **黄巾力士** | 巨汉，持巨械（大刀/石锤），肌肉裸露，黄巾包头，区别于制式军 | 纯数值蛮力，**零新机制** |
| **黄巾军（黄巾贼）** | 农民义军，装备混杂（耙/锄/竹枪），黄巾包头，衣衫褴褛 | 纯数值，低攻低防低血但 cost 1 量大 |
| 太平道兵（符兵/妖兵） | 道袍、符水、鬼神幻术感 | ⚠️ 若含施法/道术需**新机制（法术系统）**，建议本轮先不做，或仅做「持符近战」外观的数值变体 |
| 天公/地公/人公将军亲卫 | 张角兄弟卫队，黄袍 | 纯数值，黄袍视觉差异 |

**建议本轮先做**：黄巾力士 + 黄巾军（形象差异大、零新机制）。太平道术兵留待法术系统。

## 接入流程（确认后执行）

1. `troops.js` 注册 3~5 个新 key（atk/def/hp/spd/cost/upkeep/slot + 机制 flag）
2. 战斗引擎加 `weakFire` / `trample` 判定（`battlefield.js` / `combat.js` 几行）
3. AI 出征权重（`spawnTables` / 势力配置）加入新兵种
4. 豆包出图（半身，按现有规范：浓墨、统一纸色、纯墨；藤甲/象兵可微彩体现材质）
5. `tools/process_unit_art.py` 加 MAP/CROP，裁 256² WebP
6. CSS 三处登记（复用 `.bf-u-ico` / `.bf-ava-art` / `.bf-order-ico` 模式，加新 key）
7. bundle 两次 + `verify_versions.py` + 真机双视口
