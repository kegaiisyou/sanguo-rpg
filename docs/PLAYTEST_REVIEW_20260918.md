## 一、总体印象

一句话：**这是一款罕见的、把「文字 AVG 的叙事密度」和「SLG 的宏观战略层」缝得很紧的网页游戏**。它不是换皮卡牌，也不是纯文字 MUD——它有真正的州郡地理（d3 战略图 + dissolve 去重叠）、真经济（纳赋/开发/市场）、真外交（议和/结盟/招降）和真战争（群雄攻伐 + 玩家职种加成）。作为爱好者，最打动我的是**系统之间有因果链**：你占的城会产出，产出养兵，兵决定你能不能在下一场 warlordBattle 里守住，而外交状态又决定谁打你。这种"牵一发而动全身"正是 SLG 的脊梁。

当然，作为早期版本（数值与内容仍在快速迭代），它离"成品"还有打磨空间，详见第五节。

## 二、分系统深度体验

### 1. 时间 / 历法系统（骨架，稳定）
- 时辰制 + 朔日结算 + 点卯/宵禁/牢房作息约束，构成了一个有"生活节律"的世界。教学期 `clockFlowing()=false` 冻结时钟的设计很聪明——新人不被时间追着跑。
- 自动化验证：连续 60 天 `advanceMinutes(1440)` 推月、朔日结算、月份纳赋全部 0 错误。

### 2. 职种分化（⭐ 平衡性亮点，已验证生效）
捏人三选——**游侠(youxia) / 将才(jiang) / 相才(xiang)**，分别对应战斗、军事、内政三条成长曲线：
- 将才：`atk *= 1.25`（攻方战斗加成）
- 相才：纳赋 `* 1.35`、治下城开发 `* 1.35`（经济引擎）
- 游侠：招降率 `* 1.2`（外交/挖角向）

**实测数据（60 天末，各占 10~12 城）**：

| 职种 | 金币 | 占城数 | 备注 |
|------|------|--------|------|
| 游侠 youxia | 860 | 10 | 均衡 |
| 将才 jiang  | 947 | 10 | 略优（武略线需战斗才显） |
| 相才 xiang  | **1338** | 12 | 经济碾压，符合 1.35 倍预期 |

相才的金币优势（1338 vs 860）干净利落地验证了 econMul 的设计意图——**不靠数值堆砌，而靠"选择带来不同玩法"**。这是好设计的标志。

### 3. 战略层（SLG 主体，稳定）
- **占城**：`conquerCity(cid, owner, devDelta)` 写入 `ruledCities`、授予官职，链路完整。
- **外交**：`diploPropose`（议和/结盟，耗资+声望+时限）、`diploSue`（招降公式含声望/好感/实力，夹 [0.05,0.95]），关系有 war/truce/alliance 三态 + 到期清算。
- **战争**：`warlordBattle` 指定攻伐；群雄内政 AI 自主扩张。
- **朔日结算**：纳赋、开发、外交到期、势力全灭、统一终局一整套 tick。
- 自动化验证：随机占城 + 随机外交 + 周期性招降 + 周期性战争，60 天 0 错误。

### 4. 战略地图（视听享受，技术扎实）
d3 `geoPath + geoMercator` 渲染，构建期 dissolve 去重叠（61 郡 111 对相交已合并），**两级 LOD 交叉淡入淡出**（远看州、近看郡+城+标签），州名用 winding number 锚定最深内点 + 限幅碰撞避让，**标签绝不甩出州界**。小屏用收起式浮动组（填色栏 + 缩放钮）避免挡住扬州/交州。作为常看地图的 SLG 玩家，这套 LOD 与避让比很多商业页游都讲究。

### 5. 战斗系统（初始化稳定）
`startCombat('bandit')` / `startCombat('city_guard')` 战斗初始化路径验证通过，无崩溃。回合制战斗 DQ 引擎此前已抽离，结构清晰。

## 三、游玩中发现的 BUG 与修复记录

### BUG-A（本次游玩发现并修复，commit `aa49e9d` / `v20260918i`）
**症状**：进游戏后极短时间内（约 2.5s 内）会被强制"回首頁"，state 被清空。
**根因**：`engine.js` 末尾 `_waitPbg` 预加载底图超时轮询，原无条件调用 `showTitle()`。玩家若在 2.5s 内以最快路径进入游戏（真实可复现，非仅无头环境），预加载完成时已被强回首頁。进而 `advanceMinutes` 内 `clockFlowing()→onbF()` 读 `state.flags` 时 `state` 已为 null → `TypeError: Cannot read properties of null (reading 'flags')`。
**修复**：
1. `_waitPbg`：`if(!state || !state.room) showTitle();`（已进游戏则不再强回首頁）
2. `advanceMinutes` 开头加 `if(!state) return;` 守卫
3. `onbF` 加 `state` 空值防御，返回 null 而非崩溃
4. 顺手暴露 `window.advanceMinutes/advanceTime` 供自动化游玩 harness 推进时间

**影响**：修复前自动化游玩狂飙出 147 个错误；修复后归零。真实玩家"刚进游戏就被弹回首頁"的体感消失。

### BUG-B（远程已修复，commit `3eca156`）
**症状**：`conquerCity` 被调用时写死 `'player'`，与玩家实际势力键 `playerFaction`（'义军'）不一致 → `ruledCities` 不更新，占城"看似成功实则没算上"。
**修复**：改传 `playerFaction`，占城统计恢复正确。

### BUG-C（远程已修复，commit `3eca156`）
**症状**：外交到期清算用了"旧月键"比对，导致盟约/休战**多生效一个月**才被清算。
**修复**：先写新月键再跑 `onMonthTick` 清算，时序修正。

## 五、作为深度玩家的改进建议（非 BUG，体验向）
1. **战斗的"爽点"反馈**：目前 `startCombat` 初始化稳定，但战斗结算的演出/数值波动在自动化里未深入。建议补一套"战报"摘要（伤亡/缴获/声望变化），这是 SLG 玩家的核心多巴胺来源。
2. **外交的可视化深度**：关系三态已有，但建议在战略图或势力图加一条"敌我态势时间线"，让"谁和谁结盟打谁"一目了然（类似 EU4 的 Diplo 视图）。
3. **职种后期的"分水岭"事件**：相才经济碾压已验证，但将才/游侠的中后期专属事件（如将才的"威震"震慑、游侠的"侠名"招募）需要更强的内容钩子才能和相才拉开体验差异。
4. **存档与多周目**：`defaultSave.version` 是存档 schema 版本，目前迁移逻辑健全；建议加"史实/架空"两种开局线，提升重开价值。
5. **移动端手感**：州名避让与浮动组已为小屏优化；战略图双指缩放的手感（locateGuide 用 `2.6/baseT.k` 保持屏幕倍率）可再微调阻尼。
