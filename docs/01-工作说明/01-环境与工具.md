## 一、运行前提

这是个**纯静态前端项目**：无后端、无 npm 运行时依赖、不需要 `npm install` 才能玩。

```bash

```

但要触发 localStorage 存档等功能，建议用本地 HTTP 服务。

## 四、起本地服务

```bash
python serve_nocache.py
# 访问 http://127.0.0.1:8124/
```

**重要**：本地 `127.0.0.1` 源与线上 `kegaiisyou.github.io` 源的 localStorage **互不相通**。
也就是说：在线上玩出来的存档，本地看不到（反之亦然）。

需要在本地复现某个存档时，做法是把归档起来的 localStorage 值注入到页面：

```js
await page.evaluate(items => {
  items.forEach(i => { try { localStorage.setItem(i.name, i.value); } catch(e){} });
}, lsItems);
await page.reload();
```

存档键名：`lf_save_1`（另有 `sanguo_audio_on` / `sanguo_bgm_vol` / `sanguo_sfx_vol` 等设置项）。

## 五、实机测试（可选，Playwright）

用 Playwright 跑真实浏览器验证是最可靠的验收方式，尤其是**界面类 bug**（很多问题无 JS 报错，只能靠 DOM 观察发现）。

最小骨架：

```js
const { chromium } = require('playwright');
const CHROME = 'C:\\Users\\Administrator\\AppData\\Local\\ms-playwright\\chromium-1246\\chrome-win64\\chrome.exe';

const b = await chromium.launch({ executablePath: CHROME, args: ['--no-sandbox'] });
const ctx = await b.newContext({ viewport:{width:393,height:852}, isMobile:true, hasTouch:true });
const p = await ctx.newPage();

const errs = [];
p.on('pageerror', e => errs.push('PAGEERR: ' + (e.stack || e.message)));

await p.goto('http://127.0.0.1:8124/', { waitUntil: 'domcontentloaded' });
// …进入游戏、操作、断言…
console.log('errors:', errs.length);
```

常用定位技巧：

| 目的 | 代码 |
|---|---|
| 按钮中心点<br>被谁挡住 | `document.elementsFromPoint(cx,cy)[0]` |
| 是否被交互锁 | `btn.classList.contains('locked')` / `getComputedStyle(btn).pointerEvents` |
| 当前房间/天数 | `LF.Core.state.room` / `LF.Core.state.day` |
| 版本号 | `LF.CONSTANTS.VERSION` |
| 推进叙事打字 | 反复点屏幕中部跳打字机：`p.mouse.click(196,430)` |

## 六、GitHub 直连提示

本机直连 `github.com` **不通**（clone/push 走 HTTPS 会超时）。仓库 remote 配的是 SSH：

```
origin  git@github.com:kegaiisyou/sanguo-rpg.git
```

SSH 通不通取决于本机 key，详见 [03-GitHub与发布](03-GitHub与发布.md)。
