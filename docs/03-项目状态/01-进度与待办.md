## 三、交接给下一位的重要提醒

1. **改了 `shared/*.js` 一定跑 bundle（跑两次）**，否则线上完全不变。
2. **本机 `replace_in_file` 工具不可靠**（假成功），改动一律用 Python 原生 IO + 读回核验。
3. **"按钮点不动/无报错"的 bug，第一步查 `elementsFromPoint`**（多半是层叠遮挡或 `.locked` 上锁）。
4. version 四处同步：`constants.js` / `tools/bundle.py` / `index.html` 的 `bundle.js?v` 与 `game.css?v`——均无需手改，改完 `tools/bundle.py` 的 `VERSION` 后连跑两次 + `python tools/verify_versions.py` 自动对齐。
5. 新模块必须登记 `tools/bundle.manifest`。
