战斗画面重构 · 原型对比

三个方案均为零美术素材、纯代码实现。点开各自演示，凭观感决定方向。 目标：在「骑砍式千军万马」+「无双式割草演出」之间，找到不依赖美术资源也能出效果的做法。
原型 A · Canvas 兵海 + 文字演出推荐

两军数百单位在 Canvas 上对冲、混战、溃散；斩将时全屏「斬」字印章砸下 + 白光 + 慢动作。最贴近骑砍战场 + 无双割草，且性能可上万单位。

 原型 B · 纯文字电影战报

完全放弃图形，用流式巨字战报 + 关键词高亮 + 拟声词（破！斬！）+ 数字滚动推进，信长/太阁风。成本最低，但缺大场面画面感。

 原型 C · 极简几何 + 速度线

三角=兵、圆=将、线=冲锋轨迹，靠镜头震动、速度线、墨溅营造无双爽感。比写实 SVG 干净，但千军万马表现力有限。

 原型 A+B · 兵海战场 + 文字战报（组合）

底层 Canvas 兵海打千军万马（A），上层电影式文字战报推进（B），斩将触发全屏「斬」印章。兼顾大场面与叙事节奏。

 原型 · 三分隔通用战斗 UI（推荐）新 · 已落地

去掉原先写死的武侠门派（青冥剑派/血刀门/落魄剑客），改为上·中·下三分隔通用布局：上栏各方态势（支持多阵营混战、可横滚），中栏实时辞藻文字播报（铺陈间皆附具体数值、暴击/溃败触发「斬/破/溃」印章），下栏玩家择定动作倾向（猛攻/稳守/周旋/奇谋/蓄势）再推演一拍。同一套 resolve(攻×100/(100+防)) 内核，可切换 多人对战 / 军团混战 / 小规模械斗 / 攻城战役 / 辩论 等场景，向多人、军团、攻城、唇枪舌剑平滑扩展。

 原型 · 纯文字武侠（落魄剑客 · 江湖遭遇）旧 · 含虚构门派

旧方向：武侠风，落魄剑客夜走荒山。其中「青冥剑派/血刀门」系凭空编的架空武侠，与项目设定冲突，已在新原型中移除。保留作对照参考。
方向已更新：以 统一分形战斗内核 为地基，去掉写死的武侠门派，改由场景驱动各方势力（faction）。表现层为 纯文字三分隔（态势栏 + 辞藻战报 + 倾向操作），零素材、可平滑覆盖从个体侠客到门派千军、乃至多人对战·军团混战·攻城·辩论等任意形态。角色不再用卡片/头像，全凭文字描写。同一套 resolve 驱动所有尺度。
