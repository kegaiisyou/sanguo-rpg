🐞 修复：山河图内城内网格不显示

上一版 openModal('map') 的构建分支仍被写死为 buildMapKingHTML（之前的编辑因写锁竞争未生效），导致城内打开山河图只显示世界地图、看不到城内 N×N 网格。本版已改为：位于城内且非强制世界图时，渲染 buildMapCityHTML（城内布防图），并同步其初始化 initMapCity。点开山河图即可看到该城网格，当前格高亮、相邻格可点。

🏯 中央建筑按城市等级分化

为每座城市新增 tier 行政等级（capital / zhou / xian），城内正中央据此生成不同行政中心：
  • 都城（洛阳）：皇宫 🏯
  • 州城（各州治）：州衙 🏛
  • 县城（颍川及 5×5 小城）：城主府 🏛
地点标题与山河图格子名均随等级显示（洛阳·皇宫 / 邺城·州衙 / 颍川·城主府）。genCityGrid 加 GRID_VER 版本戳，旧档自动重建为新布局。

🏪 去除空泛交互，铺户具体化

不再出现「逛街/逛市集」等空泛动作，改为可交互的具体铺户（后期可直接挂真实 NPC 与专属剧情）：
  • 市集格：济世药铺（疗伤抓药·气血+45/内力+12）、锦绣布庄（置办衣甲·防御+2）、悦来食肆（打尖进食·粮草补满）、万丰杂货（采买补给·饮水补满）
  • 农庄格：庄头（问农 / 助农·粮草+12 / 购粮·粮草补满）
  • 皇宫格：宫门近臣（入宫觐见 / 叩阙陈情）
  • 衙署格：主簿/从事（参谒长官 / 问政，台词随治安·商业·归属变化）
  • 军营格：校尉（交谈 / 点卯）；其余街区保留少量百姓（交谈 / 观察）
  • 治安低于 45 时，城内仍会刷出「落单溃兵」可供挑战

📍 地点标题随格子变化

renderLocTab 现于城内时附加当前格名，文本输出口顶端显示如「洛阳 · 皇宫」「颍川 · 城主府」「邺城 · 州衙」「邺城 · 市集」等，移动后实时更新。
