🔍 本次修复：货郎物品名与价格 字号大 / 排版不齐 / 显示不全

根因一：sgFontSize() 本应按品名长度返回字号，但调用处写成了 style="font-size:'+sgFontSize(d.name)+'" —— 直接把 sg-n2~sg-n6 这类分级 class 名当字号值塞进内联样式（无效值，字体回落默认大字），且内联样式让手机断点 CSS 的 9.5px 完全覆盖不掉。

根因二：.shop-good{aspect-ratio:1/1} 把格子锁成正方形——手机端每格仅约 50px 宽，5 字品名（如"五禽戏图谱"）必然换行挤出，价格行再被 overflow:hidden 裁切，所以「显示不全、不整齐」。
