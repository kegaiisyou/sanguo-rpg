🐛 本次修复：货郎购买报错

报错信息：lfui.showbuypanel is not a function
根因：货郎商品卡片的「购买」按钮在 HTML 里写的是 onclick="LFUI.showBuyPanel(...)"， 但 window.LFUI 导出对象里漏掉了 showBuyPanel（其他按钮 confirmSell / cancelSell 等都导出了，唯独漏了它）→ 点击即抛错。
修复：把 showBuyPanel:showBuyPanel 加入 window.LFUI 导出：
window.LFUI = { ... shopSell1, shopSellAll, confirmSell, cancelSell, showBuyPanel:showBuyPanel, dismissCompanion };
顺带全面排查：逐一核对页面中所有 LFUI.xxx 调用（解散、购买、出售×1、全售、确认出售、取消、自动整理、属性折叠、卸下、装备、使用、放置、丢弃、关闭）——均已正确导出，无同类隐患。
